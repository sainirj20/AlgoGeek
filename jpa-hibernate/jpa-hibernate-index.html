JPA / Hibernate Annotation Reference

A single lookup table of the JPA and Hibernate-specific annotations that come up most often in interviews and day-to-day work — what it does, where in the code it's legal to place it, and a minimal example. Click any column header to sort — click again to reverse the order. For worked examples of most of these in context, see the Architecture & Setup, Entity Mapping, Relationships & Cascading, Entity Lifecycle, and Performance & Caching pages. Spring Data JPA-specific annotations (@Query, @Modifying, repository interfaces) live in the Spring annotation reference instead.

AnnotationScopeUsesApplies ToExample
@EntityCore / EntityMarks a class as a JPA-managed persistent entity mapped to a database table.Class@Entity public class Post { }
@TableCore / EntityCustomizes the table (and optionally schema/catalog) name an entity maps to; defaults to the class name.Class@Table(name = "posts")
@IdCore / KeysMarks a field as the entity's primary key.Field@Id private Long id;
@GeneratedValueCore / KeysSpecifies the primary-key generation strategy: IDENTITY, SEQUENCE, TABLE, or AUTO.Field@GeneratedValue(strategy = GenerationType.IDENTITY)
@SequenceGeneratorCore / KeysDefines a named database sequence generator for use with GenerationType.SEQUENCE, including the batch allocation size.Field, Class@SequenceGenerator(name = "post_seq", sequenceName = "post_seq", allocationSize = 50)
@TableGeneratorCore / KeysDefines a table-based key generator as a portable alternative to native database sequences.Field, Class@TableGenerator(name = "post_gen", table = "id_gen")
@ColumnCore / MappingCustomizes column mapping details for a field — name, nullability, length, uniqueness, precision/scale.Field@Column(name = "title", nullable = false, length = 200)
@BasicCore / MappingExplicitly marks a simple attribute mapping; mainly used to set fetch = LAZY on a non-collection field like a large @Lob.Field@Basic(fetch = FetchType.LAZY) private String content;
@TransientCore / MappingExcludes a field from persistence entirely — JPA's own annotation, distinct from (but equivalent in effect to) Java's transient keyword.Field@Transient private int wordCount;
@EnumeratedCore / MappingMaps an enum field as ORDINAL (an int, the default and a common pitfall) or STRING (the safer, recommended choice).Field@Enumerated(EnumType.STRING) private PostStatus status;
@TemporalCore / MappingMaps a legacy java.util.Date/Calendar field to a SQL DATE, TIME, or TIMESTAMP; not needed for modern java.time types.Field@Temporal(TemporalType.TIMESTAMP) private Date createdAt;
@LobCore / MappingMaps a field as a large object — CLOB for String/char[], BLOB for byte[].Field@Lob private String content;
@EmbeddableCore / MappingMarks a class as an embeddable value type with no identity or table of its own.Class@Embeddable public class Address { }
@EmbeddedCore / MappingEmbeds an @Embeddable value type's columns directly into the owning entity's table.Field@Embedded private Address address;
@EmbeddedIdCore / KeysUses an @Embeddable class as a composite primary key.Field@EmbeddedId private OrderItemId id;
@MappedSuperclassInheritanceMarks a base class whose mapped fields are inherited by @Entity subclasses, without the base class itself being a queryable entity.Class@MappedSuperclass abstract class BaseEntity { }
@InheritanceInheritanceConfigures the inheritance mapping strategy (SINGLE_TABLE, JOINED, TABLE_PER_CLASS) for an entity hierarchy.Class@Inheritance(strategy = InheritanceType.JOINED)
@DiscriminatorColumnInheritanceNames the column used to distinguish concrete subtypes in a SINGLE_TABLE inheritance hierarchy.Class@DiscriminatorColumn(name = "post_type")
@DiscriminatorValueInheritanceSets the discriminator value stored in the database row for a specific subtype.Class@DiscriminatorValue("ARTICLE")
@OneToOneRelationshipsDeclares a one-to-one association between two entities.Field@OneToOne @JoinColumn(name = "author_id") private Author author;
@OneToManyRelationshipsDeclares a one-to-many association; usually the inverse (mappedBy) side of a bidirectional relationship.Field@OneToMany(mappedBy = "author") private List<Post> posts;
@ManyToOneRelationshipsDeclares a many-to-one association — almost always the owning side, holding the foreign key column.Field@ManyToOne @JoinColumn(name = "author_id") private Author author;
@ManyToManyRelationshipsDeclares a many-to-many association, backed by a join table.Field@ManyToMany private Set<Tag> tags;
@JoinColumnRelationshipsSpecifies the foreign-key column name for an association, overriding JPA's default naming.Field@JoinColumn(name = "author_id", nullable = false)
@JoinTableRelationshipsSpecifies the join table (and its two foreign-key columns) for a many-to-many association.Field@JoinTable(name = "post_tags", joinColumns = @JoinColumn(name = "post_id"))
@OrderByRelationshipsOrders a collection association by one or more entity fields, applied at the query level (not persisted).Field@OrderBy("createdAt DESC") private List<Comment> comments;
@OrderColumnRelationshipsPersists a collection's order in a dedicated index column, preserving List ordering across reloads.Field@OrderColumn(name = "position") private List<Comment> comments;
@PrePersistLifecycleRuns exactly once, immediately before an entity is inserted.Method@PrePersist void onCreate() { }
@PostPersistLifecycleRuns exactly once, immediately after an entity is inserted.Method@PostPersist void afterCreate() { }
@PreUpdateLifecycleRuns immediately before a managed entity's changes are flushed as an UPDATE.Method@PreUpdate void onUpdate() { }
@PostUpdateLifecycleRuns immediately after an UPDATE has been flushed.Method@PostUpdate void afterUpdate() { }
@PreRemoveLifecycleRuns immediately before an entity is deleted.Method@PreRemove void onDelete() { }
@PostRemoveLifecycleRuns immediately after an entity has been deleted.Method@PostRemove void afterDelete() { }
@PostLoadLifecycleRuns immediately after an entity is loaded/hydrated from the database.Method@PostLoad void afterLoad() { }
@EntityListenersLifecycleRegisters an external listener class whose annotated methods handle this entity's lifecycle callbacks, instead of defining them on the entity itself.Class@EntityListeners(AuditingEntityListener.class)
@NamedQueryQueryingDeclares a static, named, precompiled JPQL query directly on an entity class, validated at startup rather than first use.Class@NamedQuery(name = "Post.findPublished", query = "select p from Post p where p.status = 'PUBLISHED'")
@NamedNativeQueryQueryingDeclares a static, named native SQL query directly on an entity class.Class@NamedNativeQuery(name = "Post.rawFind", query = "select * from posts", resultClass = Post.class)
@NamedEntityGraphQueryingDeclares a reusable, named entity graph specifying which lazy associations to eagerly fetch together, avoiding N+1 without hand-written JOIN FETCH.Class@NamedEntityGraph(name = "Author.withPosts", attributeNodes = @NamedAttributeNode("posts"))
@VersionConcurrencyEnables optimistic locking; the field is checked in the UPDATE's WHERE clause and incremented on every successful write.Field@Version private int version;
@CacheableCachingMarks an entity as eligible for Hibernate's second-level cache (still requires a cache provider and region factory configured).Class@Cacheable public class Tag { }
@Cache (Hibernate)CachingConfigures the second-level cache concurrency strategy for an entity — READ_ONLY, READ_WRITE, or NONSTRICT_READ_WRITE.Class@Cache(usage = CacheConcurrencyStrategy.READ_ONLY)
@NaturalId (Hibernate)Hibernate-specificMarks a business/natural key field, enabling lookup via Session#byNaturalId() independent of the surrogate @Id.Field@NaturalId private String isbn;
@DynamicUpdate (Hibernate)Hibernate-specificGenerates UPDATE statements containing only the columns that actually changed, instead of every mapped column.Class@DynamicUpdate public class Post { }
@DynamicInsert (Hibernate)Hibernate-specificGenerates INSERT statements that omit columns with null values, relying on the database's own column defaults.Class@DynamicInsert public class Post { }
@BatchSize (Hibernate)PerformanceHints Hibernate to fetch multiple lazy proxies or collections together in one batched SELECT instead of issuing them one at a time.Class, Field@BatchSize(size = 25)
@Where (Hibernate)Hibernate-specificAdds a permanent SQL restriction clause to every query Hibernate issues for the entity or collection (e.g. a soft-delete filter).Class, Field@Where(clause = "deleted = false")
@Formula (Hibernate)Hibernate-specificMaps a field to a read-only SQL expression computed at query time instead of a stored column.Field@Formula("(select count(*) from comments c where c.post_id = id)") private int commentCount;
@Immutable (Hibernate)PerformanceMarks an entity as read-only; Hibernate skips dirty-checking it entirely for a small but real performance gain on data that never changes.Class@Immutable public class Tag { }
How to use this table in an interview
The standard jakarta.persistence.* annotations (entity, keys, mapping, relationships, lifecycle) are must-knows for any JPA role. The Hibernate-specific ones (@NaturalId, @DynamicUpdate, @Where, @Formula, @BatchSize) are a level deeper — bringing one up unprompted (for example, mentioning @BatchSize when discussing N+1 fixes) signals real production experience with Hibernate specifically, not just the JPA spec.
