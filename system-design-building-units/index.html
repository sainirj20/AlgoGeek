The reusable infrastructure primitives that show up inside almost every system design interview — data storage models, caching, load balancers, message queues, coordination services, search indexes, observability, security, resilience patterns, real-time communication, big-data processing, and workflow orchestration. Master these as building blocks and you can assemble them into the answer for nearly any larger design question.
