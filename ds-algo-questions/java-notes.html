Java Notes

Quick-reference tables for the String, wrapper class, and Collections methods used throughout the solutions on this site — TreeSet/TreeMap get special attention since they show up in a lot of the trickier problems.

String — Important Methods

MethodDescriptionTime Complexity
charAt(int index)Returns the character at the given index.O(1)
length()Returns the number of characters in the string.O(1)
substring(int begin, int end)Returns a new string from begin (inclusive) to end (exclusive).O(n)
indexOf(String str)Index of the first occurrence of str, or -1.O(n·m)
lastIndexOf(String str)Index of the last occurrence of str, or -1.O(n·m)
contains(CharSequence s)Whether the string contains s.O(n·m)
equals(Object other)Content equality check.O(n)
equalsIgnoreCase(String other)Case-insensitive content equality.O(n)
compareTo(String other)Lexicographic comparison (negative/zero/positive).O(n)
toCharArray()Converts the string to a char[].O(n)
split(String regex)Splits around matches of a regex.O(n)
trim() / strip()Removes leading/trailing whitespace (strip() is Unicode-aware).O(n)
replace(char old, char new)Replaces every occurrence of a character.O(n)
replaceAll(String regex, String repl)Replaces every regex match.O(n)
toLowerCase() / toUpperCase()Case conversion.O(n)
startsWith(String prefix) / endsWith(String suffix)Prefix/suffix check.O(m)
isEmpty() / isBlank()Zero-length check / all-whitespace check.O(1) / O(n)
concat(String str)Concatenates another string, returning a new one.O(n)
String.valueOf(x)Converts int/char[]/Object/etc. to a String.O(n)
String.format(String fmt, Object... args)Builds a formatted string (printf-style).O(n)
String.join(CharSequence delim, ...)Joins elements with a delimiter.O(n)
repeat(int count)Repeats the string count times.O(n·count)
matches(String regex)Whether the entire string matches a regex.O(n), regex-dependent
chars()Returns an IntStream of character codes.O(n)

StringBuilder — Important Methods

MethodDescriptionTime Complexity
append(...)Appends to the end (String, char, int, etc.).Amortized O(1)
insert(int offset, ...)Inserts a value at a position, shifting the rest.O(n)
deleteCharAt(int index)Removes the character at index.O(n)
delete(int start, int end)Removes a range of characters.O(n)
reverse()Reverses the sequence in place.O(n)
charAt(int index) / setCharAt(int index, char c)Reads/writes a single character.O(1)
indexOf(String str)Index of the first occurrence of str.O(n·m)
toString()Converts to an immutable String (copies the buffer).O(n)
length()Current number of characters.O(1)

Wrapper Classes — Important Methods

MethodDescriptionTime Complexity
Integer.parseInt(String s)Parses a String to a primitive int.O(n)
Integer.valueOf(String s)Parses to an Integer object (caches -128..127).O(n)
Integer.toString(int i)Converts an int to its String form.O(logⁿ₀ n)
Integer.compare(int a, int b)Compares two ints without boxing.O(1)
Integer.MAX_VALUE / MIN_VALUEThe largest/smallest representable int (2147483647 / -2147483648).O(1)
Integer.bitCount(int i)Number of 1-bits in the two’s-complement representation.O(1)
Integer.toBinaryString(int i) / toHexString / toOctalStringBase-2 / 16 / 8 String representation.O(log n)
Integer.numberOfLeadingZeros(int i) / numberOfTrailingZerosCounts leading/trailing zero bits.O(1)
Integer.highestOneBit(int i) / lowestOneBitIsolates the highest/lowest set bit.O(1)
Integer.reverse(int i)Reverses the bit order of a 32-bit int.O(1)
Character.isDigit(char c)Whether c is a digit.O(1)
Character.isLetter(char c) / isLetterOrDigitWhether c is alphabetic / alphanumeric.O(1)
Character.isUpperCase(char c) / isLowerCaseCase check.O(1)
Character.toUpperCase(char c) / toLowerCaseCase conversion for a single character.O(1)
Character.getNumericValue(char c)Numeric value of a digit character (e.g. '7' -> 7).O(1)
Character.isWhitespace(char c)Whether c is whitespace.O(1)
Long.parseLong(String s)Parses a String to a primitive long.O(n)
Double.parseDouble(String s)Parses a String to a primitive double.O(n)
Boolean.parseBoolean(String s)Parses a String to boolean (true iff equalsIgnoreCase("true")).O(1)

Collections — Important Methods

MethodDescriptionTime Complexity
ArrayList.add(E e)Appends to the end.Amortized O(1)
ArrayList.add(int index, E e)Inserts at a position, shifting later elements.O(n)
ArrayList.get(int index) / set(int index, E e)Random-access read/write.O(1)
ArrayList.remove(int index)Removes at a position, shifting later elements.O(n)
ArrayList.contains(Object o)Linear search for equality.O(n)
ArrayDeque.push(E e) / pop()Stack-style insert/remove at the head.O(1)
ArrayDeque.offer(E e) / poll()Queue-style insert at tail / remove from head.O(1)
ArrayDeque.peek() / peekFirst() / peekLast()Reads without removing.O(1)
HashMap.put(K key, V value) / get(K key)Insert/lookup by key.O(1) average, O(n) worst case
HashMap.containsKey(K key) / remove(K key)Key existence check / deletion.O(1) average
HashMap.getOrDefault(K key, V def)Lookup with a fallback default.O(1) average
HashMap.merge(K key, V value, BiFunction fn)Combines an existing value with a new one (or inserts).O(1) average
HashMap.computeIfAbsent(K key, Function fn)Inserts a computed value only if the key is absent.O(1) average
HashSet.add(E e) / contains(E e) / remove(E e)Set membership operations.O(1) average
PriorityQueue.offer(E e) / poll()Insert / remove-the-min (or per Comparator).O(log n)
PriorityQueue.peek()Reads the min without removing.O(1)

TreeSet / TreeMap (Navigable Collections) — Important Methods

MethodDescriptionTime Complexity
add(E e) / remove(E e) / contains(E e)Standard set operations, kept in sorted order.O(log n)
first() / last()Smallest / largest element currently in the set.O(log n)
floor(E e)Greatest element ≤ e, or null.O(log n)
ceiling(E e)Smallest element ≥ e, or null.O(log n)
lower(E e)Greatest element strictly < e, or null.O(log n)
higher(E e)Smallest element strictly > e, or null.O(log n)
pollFirst() / pollLast()Removes and returns the smallest / largest element.O(log n)
headSet(E toElement) / tailSet(E fromElement)View of elements < toElement / ≥ fromElement.O(log n) to create, view-backed
subSet(E from, E to)View of elements in [from, to).O(log n) to create, view-backed
descendingSet() / descendingIterator()Reverse-ordered view / iterator.O(1) to obtain
size()Number of elements.O(1)
TreeMap.floorKey(K) / ceilingKey(K) / lowerKey(K) / higherKey(K)Same idea as TreeSet, keyed lookup.O(log n)
TreeMap.firstEntry() / lastEntry() / pollFirstEntry() / pollLastEntry()Endpoint entry access/removal.O(log n)
