Triangle

Problem

Given a triangle array (a list of rows, each one element longer than the last), find the minimum path sum from the top to the bottom, where at each step you may move to an adjacent number in the row below (index i or i+1).

ExampleInput: triangle = [[2],[3,4],[6,5,7],[4,1,8,3]] Output: 11 (path 2 + 3 + 5 + 1)

Approach

Bottom-up DP: start from the second-to-last row and work upward. For each element, add the smaller of the two adjacent values directly below it in the next row (already reduced to a minimal path sum in a prior iteration), collapsing the triangle one row at a time until only the top single value remains -- that final value is the minimum total path sum. Using a single reusable array sized to the bottom row keeps this O(n) extra space instead of storing the whole triangle's DP table.

Time O(n^2)Space O(n)
Java
public int minimumTotal(List<List<Integer>> triangle) {
    int n = triangle.size();
    int[] dp = new int[n + 1];

    for (int row = n - 1; row >= 0; row--) {
        List<Integer> currentRow = triangle.get(row);
        for (int col = 0; col < currentRow.size(); col++) {
            dp[col] = currentRow.get(col) + Math.min(dp[col], dp[col + 1]);
        }
    }

    return dp[0];
}
