🔒Paint House II

Problem

Same as Paint House, but with k colors instead of 3.

ExampleInput: costs = [[1,5,3],[2,9,4]] Output: 5
📷Diagram placeholder — paste the array traversal image here (save it into this problem's folder and set diagram in solutions.py).
LeetCode #265 (Premium)

Approach

Track, for the previous house, the smallest and second-smallest total cost across all k colors, along with which color achieved the smallest. For each house and each color, the cost is that color's paint cost plus the previous house's smallest total cost -- unless this color IS the one that achieved that smallest cost, in which case the second-smallest must be used instead (to keep adjacent colors different).

Time O(n * k)Space O(1)
Java
public int minCostII(int[][] costs) {
    int n = costs.length;
    if (n == 0) {
        return 0;
    }
    int k = costs[0].length;

    int prevMin = 0, prevSecondMin = 0, prevMinIndex = -1;

    for (int house = 0; house < n; house++) {
        int currentMin = Integer.MAX_VALUE, currentSecondMin = Integer.MAX_VALUE, currentMinIndex = -1;

        for (int color = 0; color < k; color++) {
            int cost = costs[house][color] + (color == prevMinIndex ? prevSecondMin : prevMin);

            if (cost < currentMin) {
                currentSecondMin = currentMin;
                currentMin = cost;
                currentMinIndex = color;
            } else if (cost < currentSecondMin) {
                currentSecondMin = cost;
            }
        }

        prevMin = currentMin;
        prevSecondMin = currentSecondMin;
        prevMinIndex = currentMinIndex;
    }

    return prevMin;
}
