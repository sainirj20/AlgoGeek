Best Time to Buy and Sell Stock

Problem

Given an array of stock prices by day, find the maximum profit from a single buy followed by a single sell (buy must happen before sell).

ExampleInput: prices = [7,1,5,3,6,4] Output: 5
📷Diagram placeholder — paste the array traversal image here (save it into this problem's folder and set diagram in solutions.py).
LeetCode #121

Approach

Scan once, tracking the minimum price seen so far and the best profit achievable by selling at the current price (currentPrice - minPriceSoFar), updating both as prices are processed left to right.

Time O(n)Space O(1)
Java
public int maxProfit(int[] prices) {
    int minPrice = Integer.MAX_VALUE;
    int maxProfit = 0;

    for (int price : prices) {
        minPrice = Math.min(minPrice, price);
        maxProfit = Math.max(maxProfit, price - minPrice);
    }

    return maxProfit;
}
