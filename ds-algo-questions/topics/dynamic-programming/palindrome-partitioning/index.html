Palindrome Partitioning

Problem

Given a string, partition it so every substring is a palindrome, and return all possible partitionings.

ExampleInput: s = "aab" Output: [["a","a","b"],["aa","b"]]

LeetCode #131

Approach

Backtracking over a start index: at each step, try every substring starting there as the next partition piece, only recursing further if that piece is itself a palindrome. Succeed once the start index reaches the end of the string.

Time O(n * 2^n)Space O(n)
Java
public List<List<String>> partition(String s) {
    List<List<String>> result = new ArrayList<>();
    backtrack(s, 0, new ArrayList<>(), result);
    return result;
}

private void backtrack(String s, int start, List<String> current, List<List<String>> result) {
    if (start == s.length()) {
        result.add(new ArrayList<>(current));
        return;
    }

    for (int end = start + 1; end <= s.length(); end++) {
        String piece = s.substring(start, end);
        if (isPalindrome(piece)) {
            current.add(piece);
            backtrack(s, end, current, result);
            current.remove(current.size() - 1);
        }
    }
}

private boolean isPalindrome(String s) {
    int left = 0, right = s.length() - 1;
    while (left < right) {
        if (s.charAt(left++) != s.charAt(right--)) {
            return false;
        }
    }
    return true;
}
