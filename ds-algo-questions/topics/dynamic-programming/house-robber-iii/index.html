House Robber III

Problem

Houses are arranged as a binary tree; two directly-connected houses (parent and child) cannot both be robbed. Find the maximum amount that can be robbed.

ExampleInput: root = [3,2,3,null,3,null,1] Output: 7
📷Diagram placeholder — paste the array traversal image here (save it into this problem's folder and set diagram in solutions.py).
LeetCode #337

Approach

Bottom-up DFS returning a pair per node: the best result if this node IS robbed, and the best result if it is NOT. Robbing a node forces both children to be excluded (node.val + leftExcluded + rightExcluded); not robbing it allows each child to independently be either robbed or not, so it takes the maximum of each child's pair.

Time O(n)Space O(h)
Java
public int rob(TreeNode root) {
    int[] result = dfs(root);
    return Math.max(result[0], result[1]);
}

private int[] dfs(TreeNode node) {
    if (node == null) {
        return new int[]{0, 0};
    }

    int[] left = dfs(node.left);
    int[] right = dfs(node.right);

    int robbed = node.val + left[1] + right[1];
    int notRobbed = Math.max(left[0], left[1]) + Math.max(right[0], right[1]);

    return new int[]{robbed, notRobbed};
}
