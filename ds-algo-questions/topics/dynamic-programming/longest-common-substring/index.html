Longest Common Substring

Problem

Given two strings, find the length of their longest common CONTIGUOUS substring (unlike the subsequence version, the matched characters must be adjacent in both strings).

ExampleInput: s1 = "abcdxyz", s2 = "xyzabcd" Output: 4 ("abcd" or "xyz" -- abcd is longer)
📷Diagram placeholder — paste the array traversal image here (save it into this problem's folder and set diagram in solutions.py).
Classic interview question

Approach

DP where dp[i][j] is the length of the common substring ending exactly at s1[i-1] and s2[j-1]. If those characters match, dp[i][j] = dp[i-1][j-1] + 1 (extending the previous match); otherwise it resets to 0 (since the match must be contiguous). Track the maximum value seen anywhere in the table as the answer.

Time O(m * n)Space O(m * n)
Java
public int longestCommonSubstring(String s1, String s2) {
    int m = s1.length(), n = s2.length();
    int[][] dp = new int[m + 1][n + 1];
    int maxLen = 0;

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (s1.charAt(i - 1) == s2.charAt(j - 1)) {
                dp[i][j] = dp[i - 1][j - 1] + 1;
                maxLen = Math.max(maxLen, dp[i][j]);
            }
        }
    }

    return maxLen;
}
