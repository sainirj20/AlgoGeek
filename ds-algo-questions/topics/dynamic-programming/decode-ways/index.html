Decode Ways

Problem

Given a string of digits where 'A'-'Z' map to 1-26, count the number of ways to decode it.

ExampleInput: s = "226" Output: 3 ("2 2 6", "22 6", "2 26")

LeetCode #91

Approach

DP where dp[i] is the number of ways to decode the first i characters. A single non-zero digit at position i-1 contributes dp[i-1] ways; a valid two-digit group (10-26) ending at position i-1 contributes dp[i-2] more ways -- both are added together (when applicable) to form dp[i].

Time O(n)Space O(1)
Java
public int numDecodings(String s) {
    if (s.isEmpty() || s.charAt(0) == '0') {
        return 0;
    }

    int prev2 = 1, prev1 = 1;

    for (int i = 1; i < s.length(); i++) {
        int current = 0;

        if (s.charAt(i) != '0') {
            current += prev1;
        }

        int twoDigit = Integer.parseInt(s.substring(i - 1, i + 1));
        if (twoDigit >= 10 && twoDigit <= 26) {
            current += prev2;
        }

        prev2 = prev1;
        prev1 = current;
    }

    return prev1;
}
