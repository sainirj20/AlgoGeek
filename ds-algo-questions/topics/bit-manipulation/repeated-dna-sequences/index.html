Repeated DNA Sequences

Problem

Given a DNA sequence string (only 'A', 'C', 'G', 'T'), find all 10-letter-long substrings that occur more than once.

ExampleInput: s = "AAAAACCCCCAAAAACCCCCCAAAAAGGGTTT" Output: ["AAAAACCCCC","CCCCCAAAAA"]

LeetCode #187

Approach

Encode each of the 4 DNA letters as 2 bits, so any 10-letter window fits into a 20-bit integer. Slide this window across the string, maintaining the rolling bit-encoded value (shift left by 2 and OR in the next letter's 2-bit code, masking off bits beyond 20), and track each encoding's occurrence count in a HashMap; report any encoding whose count reaches exactly 2 (adding it to the result the first time it becomes a repeat).

Time O(n)Space O(n)
Java
public List<String> findRepeatedDnaSequences(String s) {
    Map<Character, Integer> code = Map.of('A', 0, 'C', 1, 'G', 2, 'T', 3);
    List<String> result = new ArrayList<>();
    if (s.length() < 10) {
        return result;
    }

    Map<Integer, Integer> seen = new HashMap<>();
    int hash = 0;
    int mask = (1 << 20) - 1;

    for (int i = 0; i < s.length(); i++) {
        hash = ((hash << 2) | code.get(s.charAt(i))) & mask;

        if (i >= 9) {
            int count = seen.merge(hash, 1, Integer::sum);
            if (count == 2) {
                result.add(s.substring(i - 9, i + 1));
            }
        }
    }

    return result;
}
