Counting Bits

Problem

Given an integer n, return an array where the ith element is the number of set bits in i, for every i from 0 to n.

ExampleInput: n = 5 Output: [0,1,1,2,1,2]
📷Diagram placeholder — paste the array traversal image here (save it into this problem's folder and set diagram in solutions.py).
LeetCode #338

Approach

DP reusing previously computed results: dp[i] = dp[i >> 1] + (i & 1), since dropping the lowest bit of i (via a right shift) reduces to a smaller already-computed value, and the lowest bit itself just adds 0 or 1.

Time O(n)Space O(n) (excluding output)
Java
public int[] countBits(int n) {
    int[] dp = new int[n + 1];

    for (int i = 1; i <= n; i++) {
        dp[i] = dp[i >> 1] + (i & 1);
    }

    return dp;
}
