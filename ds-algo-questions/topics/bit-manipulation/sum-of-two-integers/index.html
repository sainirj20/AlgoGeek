Sum of Two Integers

Problem

Given two integers, compute their sum without using the + or - operators.

ExampleInput: a = 1, b = 2 Output: 3
📷Diagram placeholder — paste the array traversal image here (save it into this problem's folder and set diagram in solutions.py).
LeetCode #371

Approach

Simulate binary addition directly: a XOR b gives the sum of each bit position ignoring carries, while (a AND b) << 1 gives the carry that needs to be added in. Repeat this (treating the XOR result as the new a and the shifted carry as the new b) until there's no carry left.

Time O(1) (bounded by 32 bits)Space O(1)
Java
public int getSum(int a, int b) {
    while (b != 0) {
        int carry = (a & b) << 1;
        a = a ^ b;
        b = carry;
    }
    return a;
}
