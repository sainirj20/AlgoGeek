UTF-8 Validation

Problem

Given an array of integers representing bytes of data, determine whether it is a valid UTF-8 encoding.

ExampleInput: data = [197,130,1] Output: true (a 2-byte char followed by a 1-byte char)

LeetCode #393

Approach

Read each byte's leading bits to determine whether it starts a new character: a leading 0 bit means a 1-byte character; leading 110, 1110, or 11110 mean 2, 3, or 4-byte characters respectively. Once a multi-byte character's length is known, verify that exactly that many CONTINUATION bytes follow, each required to start with the bit pattern 10.

Time O(n)Space O(1)
Java
public boolean validUtf8(int[] data) {
    int i = 0;

    while (i < data.length) {
        int byteVal = data[i];
        int numBytes;

        if ((byteVal & 0b10000000) == 0) {
            numBytes = 1;
        } else if ((byteVal & 0b11100000) == 0b11000000) {
            numBytes = 2;
        } else if ((byteVal & 0b11110000) == 0b11100000) {
            numBytes = 3;
        } else if ((byteVal & 0b11111000) == 0b11110000) {
            numBytes = 4;
        } else {
            return false;
        }

        if (i + numBytes > data.length) {
            return false;
        }

        for (int j = 1; j < numBytes; j++) {
            if ((data[i + j] & 0b11000000) != 0b10000000) {
                return false;
            }
        }

        i += numBytes;
    }

    return true;
}
