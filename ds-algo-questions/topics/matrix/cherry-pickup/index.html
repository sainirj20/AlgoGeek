Cherry Pickup

Problem

Starting at the top-left of a grid containing cherries (1), empty cells (0), and thorns (-1), travel to the bottom-right and back to the top-left (moving only right/down on the way there, and only left/up on the way back), collecting the maximum number of cherries. A cherry can only be collected once.

ExampleInput: grid = [[0,1,-1],[1,0,-1],[1,1,1]] Output: 5

Approach

Reframe the round trip as two people walking from top-left to bottom-right simultaneously (equivalent to one forward trip and one reversed return trip taken step for step). Since both people take the same number of steps at any given time, their positions are (r1, step-r1) and (r2, step-r2) -- state can be tracked with just (step, r1, r2). DP over that 3D state takes the best of all 4 possible move combinations, awarding a cell's cherry once if both people land on the same cell, or both cherries otherwise.

Time O(n^3)Space O(n^3)
Java
public int cherryPickup(int[][] grid) {
    int n = grid.length;
    int[][][] memo = new int[n][n][n];
    for (int[][] plane : memo) {
        for (int[] row : plane) {
            Arrays.fill(row, Integer.MIN_VALUE);
        }
    }

    int result = dp(grid, 0, 0, 0, memo);
    return Math.max(result, 0);
}

private int dp(int[][] grid, int r1, int r2, int step, int[][][] memo) {
    int n = grid.length;
    int c1 = step - r1, c2 = step - r2;

    if (r1 >= n || r2 >= n || c1 >= n || c2 >= n || c1 < 0 || c2 < 0
            || grid[r1][c1] == -1 || grid[r2][c2] == -1) {
        return Integer.MIN_VALUE;
    }
    if (r1 == n - 1 && c1 == n - 1) {
        return grid[r1][c1];
    }
    if (memo[r1][r2][step] != Integer.MIN_VALUE) {
        return memo[r1][r2][step];
    }

    int cherries = grid[r1][c1];
    if (r1 != r2) {
        cherries += grid[r2][c2];
    }

    int best = Integer.MIN_VALUE;
    best = Math.max(best, dp(grid, r1 + 1, r2 + 1, step + 1, memo));
    best = Math.max(best, dp(grid, r1 + 1, r2, step + 1, memo));
    best = Math.max(best, dp(grid, r1, r2 + 1, step + 1, memo));
    best = Math.max(best, dp(grid, r1, r2, step + 1, memo));

    int result = best == Integer.MIN_VALUE ? Integer.MIN_VALUE : cherries + best;
    memo[r1][r2][step] = result;
    return result;
}
