🔒Number of Islands II

Problem

Given an m x n grid of water, and a sequence of positions that get turned into land one at a time, return the number of islands after each addition.

ExampleInput: m = 3, n = 3, positions = [[0,0],[0,1],[1,2],[2,1]] Output: [1,1,2,3]

Approach

A union-find (disjoint set) that supports dynamic additions: keep every cell initially as its own island (or 'not yet land'). When a cell turns to land, mark it as its own new island, incrementing a running island count, then union it with any of its 4 already-land neighbors, decrementing the count once per successful merge (union of two different sets).

Time O(k α(mn))Space O(mn)
Java
public List<Integer> numIslands2(int m, int n, int[][] positions) {
    int[] parent = new int[m * n];
    Arrays.fill(parent, -1);
    int[] islandCount = {0};
    List<Integer> result = new ArrayList<>();
    int[][] dirs = {{0, 1}, {0, -1}, {1, 0}, {-1, 0}};

    for (int[] pos : positions) {
        int id = pos[0] * n + pos[1];
        if (parent[id] != -1) {
            result.add(islandCount[0]);
            continue;
        }

        parent[id] = id;
        islandCount[0]++;

        for (int[] d : dirs) {
            int nr = pos[0] + d[0], nc = pos[1] + d[1];
            if (nr < 0 || nr >= m || nc < 0 || nc >= n) {
                continue;
            }
            int neighborId = nr * n + nc;
            if (parent[neighborId] == -1) {
                continue;
            }
            int rootA = find(parent, id);
            int rootB = find(parent, neighborId);
            if (rootA != rootB) {
                parent[rootA] = rootB;
                islandCount[0]--;
            }
        }

        result.add(islandCount[0]);
    }

    return result;
}

private int find(int[] parent, int x) {
    while (parent[x] != x) {
        parent[x] = parent[parent[x]];
        x = parent[x];
    }
    return x;
}
