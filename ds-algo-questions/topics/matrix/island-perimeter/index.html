Island Perimeter

Problem

Given a grid representing a single island (no lakes) with no diagonal connections, return the perimeter of the island.

ExampleInput: grid = [[0,1,0,0],[1,1,1,0],[0,1,0,0],[1,1,0,0]] Output: 16

Approach

For every land cell, it contributes 4 to the perimeter minus 2 for every adjacent land neighbor (right and down are enough to check, since each shared edge gets counted exactly once this way). Summing this over all land cells gives the total perimeter.

Time O(mn)Space O(1)
Java
public int islandPerimeter(int[][] grid) {
    int rows = grid.length, cols = grid[0].length;
    int perimeter = 0;

    for (int r = 0; r < rows; r++) {
        for (int c = 0; c < cols; c++) {
            if (grid[r][c] == 0) {
                continue;
            }

            perimeter += 4;
            if (r + 1 < rows && grid[r + 1][c] == 1) {
                perimeter -= 2;
            }
            if (c + 1 < cols && grid[r][c + 1] == 1) {
                perimeter -= 2;
            }
        }
    }

    return perimeter;
}
