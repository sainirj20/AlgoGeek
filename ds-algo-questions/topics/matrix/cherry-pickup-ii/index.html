Cherry Pickup II

Problem

Two robots start at the top-left and top-right corners of a grid of cherries. Each moves down one row at a time, choosing to stay, move left, or move right by one column. Maximize total cherries collected (each cell's cherry counted once even if both robots visit it).

ExampleInput: grid = [[3,1,1],[2,5,1],[1,5,5],[2,1,1]] Output: 24

Approach

DP over state (row, col1, col2): from each state, try all 9 combinations of the two robots' moves (each robot: stay/left/right) for the next row, adding the current row's cherries (counted once if both columns match), and taking the maximum over all next states, memoizing to avoid recomputation.

Time O(rows * cols^2)Space O(rows * cols^2)
Java
private Integer[][][] memo;
private int rows, cols;
private int[][] grid;

public int cherryPickup(int[][] grid) {
    this.grid = grid;
    rows = grid.length;
    cols = grid[0].length;
    memo = new Integer[rows][cols][cols];
    return dp(0, 0, cols - 1);
}

private int dp(int row, int col1, int col2) {
    if (row == rows) {
        return 0;
    }
    if (memo[row][col1][col2] != null) {
        return memo[row][col1][col2];
    }

    int cherries = grid[row][col1];
    if (col1 != col2) {
        cherries += grid[row][col2];
    }

    int best = 0;
    for (int d1 = -1; d1 <= 1; d1++) {
        for (int d2 = -1; d2 <= 1; d2++) {
            int nc1 = col1 + d1, nc2 = col2 + d2;
            if (nc1 >= 0 && nc1 < cols && nc2 >= 0 && nc2 < cols) {
                best = Math.max(best, dp(row + 1, nc1, nc2));
            }
        }
    }

    int result = cherries + best;
    memo[row][col1][col2] = result;
    return result;
}
