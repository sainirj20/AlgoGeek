Path with Maximum Gold

Problem

Given a grid where each cell holds an amount of gold (0 if empty), collect the maximum gold possible by starting at any cell, moving to any of the 4 adjacent cells, never visiting a cell twice or a cell with 0 gold.

ExampleInput: grid = [[0,6,0],[5,8,7],[0,9,0]] Output: 24

Approach

Backtracking DFS starting from every cell with gold: collect the current cell's gold, temporarily zero it out to mark it visited, recurse into all 4 neighbors taking the best result, then restore the cell's gold before returning (undoing the visit so other starting paths can use it).

Time O(mn * 4^(mn)) worst case (bounded by 25 gold cells)Space O(mn)
Java
public int getMaximumGold(int[][] grid) {
    int best = 0;

    for (int r = 0; r < grid.length; r++) {
        for (int c = 0; c < grid[0].length; c++) {
            if (grid[r][c] > 0) {
                best = Math.max(best, dfs(grid, r, c));
            }
        }
    }

    return best;
}

private int dfs(int[][] grid, int r, int c) {
    if (r < 0 || r >= grid.length || c < 0 || c >= grid[0].length || grid[r][c] == 0) {
        return 0;
    }

    int gold = grid[r][c];
    grid[r][c] = 0;

    int best = Math.max(
        Math.max(dfs(grid, r + 1, c), dfs(grid, r - 1, c)),
        Math.max(dfs(grid, r, c + 1), dfs(grid, r, c - 1))
    );

    grid[r][c] = gold;
    return gold + best;
}
