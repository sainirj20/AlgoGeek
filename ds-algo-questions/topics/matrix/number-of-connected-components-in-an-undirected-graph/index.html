🔒Number of Connected Components in an Undirected Graph

Problem

Given n nodes labeled 0 to n-1 and a list of undirected edges, count the number of connected components in the graph.

ExampleInput: n = 5, edges = [[0,1],[1,2],[3,4]] Output: 2

Approach

Union-find: start with n separate components, and for every edge, union its two endpoints, decrementing the component count whenever the union actually merges two previously-separate sets.

Time O(E α(n))Space O(n)
Java
public int countComponents(int n, int[][] edges) {
    int[] parent = new int[n];
    for (int i = 0; i < n; i++) {
        parent[i] = i;
    }

    int count = n;
    for (int[] edge : edges) {
        int rootA = find(parent, edge[0]);
        int rootB = find(parent, edge[1]);
        if (rootA != rootB) {
            parent[rootA] = rootB;
            count--;
        }
    }

    return count;
}

private int find(int[] parent, int x) {
    while (parent[x] != x) {
        parent[x] = parent[parent[x]];
        x = parent[x];
    }
    return x;
}
