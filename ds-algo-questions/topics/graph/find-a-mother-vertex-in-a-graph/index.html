Find a Mother Vertex in a Graph

Problem

A mother vertex in a directed graph is a vertex from which every other vertex is reachable. Find a mother vertex if one exists (return -1 if none does).

ExampleInput: edges = [[0,1],[0,2],[1,2],[2,0],[2,3],[3,3]] Output: 0 (or 2, both are valid mother vertices)

Approach

Uses the same key insight as the first pass of Kosaraju's SCC algorithm: run DFS from every unvisited vertex (in any order), and keep track of the LAST vertex whose DFS call finishes. That last-finished vertex is guaranteed to be a mother vertex candidate IF a mother vertex exists at all (it belongs to the 'sink' strongly-connected component in the condensation graph, i.e. the last one finished must be able to reach everything already visited). A single verification DFS from that candidate then confirms whether it actually reaches every vertex.

Time O(V + E)Space O(V)
Java
public int findMotherVertex(int n, List<List<Integer>> adj) {
    boolean[] visited = new boolean[n];
    int lastFinished = -1;

    for (int i = 0; i < n; i++) {
        if (!visited[i]) {
            dfs(i, adj, visited);
            lastFinished = i;
        }
    }

    boolean[] check = new boolean[n];
    dfs(lastFinished, adj, check);

    for (boolean reached : check) {
        if (!reached) {
            return -1;
        }
    }

    return lastFinished;
}

private void dfs(int node, List<List<Integer>> adj, boolean[] visited) {
    visited[node] = true;
    for (int neighbor : adj.get(node)) {
        if (!visited[neighbor]) {
            dfs(neighbor, adj, visited);
        }
    }
}
