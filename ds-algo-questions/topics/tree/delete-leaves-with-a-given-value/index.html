Delete Leaves With a Given Value

Problem

Given the root of a binary tree and an integer target, repeatedly delete leaf nodes with value target (a node made into a leaf by earlier deletions may itself then be deleted) until no such leaves remain.

ExampleInput: root = [1,2,3,2,null,2,4], target = 2 Output: [1,null,3,null,4]

Approach

Bottom-up DFS: recursively process both children first, so any deletions that turn a node into a target-valued leaf are already reflected. After processing, if the current node has become a leaf (both children null) and its value equals target, return null to delete it; otherwise return the node unchanged.

Time O(n)Space O(h)
Java
public TreeNode removeLeafNodes(TreeNode root, int target) {
    if (root == null) {
        return null;
    }

    root.left = removeLeafNodes(root.left, target);
    root.right = removeLeafNodes(root.right, target);

    if (root.left == null && root.right == null && root.val == target) {
        return null;
    }

    return root;
}
