Add and Search Word - Data structure design

Problem

Design a data structure supporting addWord(word) and search(word), where search can contain the wildcard '.' that matches any single letter.

ExampleaddWord("bad"); addWord("dad"); addWord("mad"); search("pad") -> false search(".ad") -> true search("b..") -> true

Approach

Store words in a Trie exactly as in Implement Trie. Searching needs DFS instead of a simple walk: at a normal letter, follow the matching child (fail if it's missing); at a '.', try every non-null child branch recursively, succeeding if any branch leads to a full match.

Time O(26^m) worst case for wildcard-heavy queriesSpace O(total letters inserted)
Java
class WordDictionary {
    private WordDictionary[] children = new WordDictionary[26];
    private boolean isWord = false;

    public void addWord(String word) {
        WordDictionary node = this;
        for (char c : word.toCharArray()) {
            int idx = c - 'a';
            if (node.children[idx] == null) {
                node.children[idx] = new WordDictionary();
            }
            node = node.children[idx];
        }
        node.isWord = true;
    }

    public boolean search(String word) {
        return dfs(word, 0);
    }

    private boolean dfs(String word, int index) {
        if (index == word.length()) {
            return isWord;
        }

        char c = word.charAt(index);
        if (c == '.') {
            for (WordDictionary child : children) {
                if (child != null && child.dfs(word, index + 1)) {
                    return true;
                }
            }
            return false;
        }

        WordDictionary child = children[c - 'a'];
        return child != null && child.dfs(word, index + 1);
    }
}
