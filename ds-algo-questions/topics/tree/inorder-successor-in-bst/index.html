🔒Inorder Successor in BST

Problem

Given the root of a binary search tree and a node p in it, find the inorder successor of p (the node with the smallest value greater than p.val), or null if none exists.

ExampleInput: root = [2,1,3], p = 1 Output: 2

Approach

Walk down from the root like a BST search for p.val: whenever the current node's value is greater than p.val, it's a candidate successor (record it, then try going further left for something even closer); whenever it's smaller or equal, move right. The last recorded candidate is the true successor.

Time O(h)Space O(1)
Java
public TreeNode inorderSuccessor(TreeNode root, TreeNode p) {
    TreeNode successor = null;

    while (root != null) {
        if (p.val < root.val) {
            successor = root;
            root = root.left;
        } else {
            root = root.right;
        }
    }

    return successor;
}
