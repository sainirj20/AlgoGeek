🔒Closest Binary Search Tree Value

Problem

Given the root of a binary search tree and a target value, find the value in the tree closest to the target.

ExampleInput: root = [4,2,5,1,3], target = 3.714286 Output: 4

Approach

Walk down the tree the same way a BST search would: at each node, compare its value to the running closest value; move left if the target is smaller than the current node, right if larger. Since a BST search only explores one path from root to leaf, this finds the closest value in logarithmic time.

Time O(h)Space O(1)
Java
public int closestValue(TreeNode root, double target) {
    int closest = root.val;

    while (root != null) {
        if (Math.abs(root.val - target) < Math.abs(closest - target)) {
            closest = root.val;
        }
        root = target < root.val ? root.left : root.right;
    }

    return closest;
}
