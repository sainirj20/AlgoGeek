🔒Inorder Successor in BST II

Problem

Given a node in a binary search tree where each node also has a pointer to its parent, find that node's inorder successor, without access to the tree's root.

ExampleInput: node = 1 in a tree [2,1,3] (1 has parent 2) Output: node with value 2

LeetCode #510 (Premium)

Approach

If the node has a right child, the successor is the leftmost node of that right subtree. Otherwise, walk up via parent pointers until finding an ancestor that is the left child of its own parent -- that parent is the successor (a right-child chain upward means every one of those ancestors is 'smaller', so none of them qualifies).

Time O(h)Space O(1)
Java
class Node {
    int val;
    Node left, right, parent;
}

public Node inorderSuccessor(Node node) {
    if (node.right != null) {
        Node current = node.right;
        while (current.left != null) {
            current = current.left;
        }
        return current;
    }

    Node current = node;
    while (current.parent != null && current.parent.right == current) {
        current = current.parent;
    }

    return current.parent;
}
