Task Scheduler

Problem

Given an array of tasks (letters) and a cooldown n (the minimum interval between two same tasks), find the minimum number of time units (including idle units) needed to finish all tasks.

ExampleInput: tasks = ["A","A","A","B","B","B"], n = 2 Output: 8 ("A B idle A B idle A B")

Approach

A math formula based on the most frequent task: if maxFreq is the highest task frequency and maxCount is how many tasks share that frequency, the schedule needs at least (maxFreq - 1) * (n + 1) + maxCount slots (accounting for idle gaps after every occurrence of the most frequent tasks except the last). The final answer is the larger of that formula and simply the total number of tasks (since with enough distinct tasks, no idle time is ever needed).

Time O(n)Space O(1) (26 letters)
Java
public int leastInterval(char[] tasks, int n) {
    int[] freq = new int[26];
    for (char task : tasks) {
        freq[task - 'A']++;
    }

    int maxFreq = 0;
    for (int f : freq) {
        maxFreq = Math.max(maxFreq, f);
    }

    int maxCount = 0;
    for (int f : freq) {
        if (f == maxFreq) {
            maxCount++;
        }
    }

    int formulaSlots = (maxFreq - 1) * (n + 1) + maxCount;
    return Math.max(formulaSlots, tasks.length);
}
