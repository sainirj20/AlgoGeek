Merge k Sorted Arrays

Problem

Given k sorted integer arrays, merge them into a single sorted array.

ExampleInput: arrays = [[1,4,5],[1,3,4],[2,6]] Output: [1,1,2,3,4,4,5,6]
Classic interview question

Approach

Use a min-heap seeded with the first element of each array (tracking which array and index each heap entry came from). Repeatedly pop the smallest element into the result, then push the next element from that same array, if one remains.

Time O(n log k)Space O(k)
Java
class ArrayContainer implements Comparable {
	int[] arr;
	int index;
 
	public ArrayContainer(int[] arr, int index) {
		this.arr = arr;
		this.index = index;
	}
 
	@Override
	public int compareTo(ArrayContainer o) {
		return this.arr[this.index] - o.arr[o.index];
	}
}

      ArrayContainer ac = queue.poll();
      result[m++]=ac.arr[ac.index];

      if(ac.index < ac.arr.length-1){
        queue.add(new ArrayContainer(ac.arr, ac.index+1));
      }
    }

    return result;

    return result;
}
