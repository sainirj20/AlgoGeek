Find Mode in Binary Search Tree

Problem

Given the root of a binary search tree with duplicate values allowed, return all the mode(s) (values that appear most frequently).

ExampleInput: root = [1,null,2,2] Output: [2]

LeetCode #501 Original write-up ↗

Approach

Inorder traversal visits equal values consecutively (since it's a BST), so a single pass can track a running streak length against the previous value: extend the streak when the value repeats, otherwise reset it to 1. Whenever the current streak matches the maximum streak seen so far, add the value to the result (clearing the result first if a strictly longer streak appears).

Time O(n)Space O(h)
Java
private Integer prevVal = null;
private int streak = 0;
private int maxStreak = 0;
private List<Integer> modes = new ArrayList<>();

public int[] findMode(TreeNode root) {
    inorder(root);
    int[] result = new int[modes.size()];
    for (int i = 0; i < result.length; i++) {
        result[i] = modes.get(i);
    }
    return result;
}

private void inorder(TreeNode node) {
    if (node == null) {
        return;
    }

    inorder(node.left);

    if (prevVal != null && prevVal == node.val) {
        streak++;
    } else {
        streak = 1;
    }

    if (streak > maxStreak) {
        maxStreak = streak;
        modes.clear();
        modes.add(node.val);
    } else if (streak == maxStreak) {
        modes.add(node.val);
    }

    prevVal = node.val;
    inorder(node.right);
}
