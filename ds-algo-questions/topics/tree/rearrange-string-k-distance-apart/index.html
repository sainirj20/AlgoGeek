🔒Rearrange String k Distance Apart

Problem

Given a string and an integer k, rearrange it so identical characters are at least k apart, or return an empty string if impossible.

ExampleInput: s = "aabbcc", k = 3 Output: "abcabc"
LeetCode #358 (Premium)

Approach

Greedily place the currently most frequent remaining character each step, using a max-heap keyed by frequency. After placing a character, put it into a waiting queue with a 'cooldown' of k steps; once that cooldown expires (the queue reaches size k), the character becomes eligible for the heap again. If the heap ever empties while characters remain waiting and unplaced, arrangement is impossible.

Time O(n log 26)Space O(n)
Java
public String rearrangeString(String s, int k) {
    if (k <= 1) {
        return s;
    }

    Map<Character, Integer> freq = new HashMap<>();
    for (char c : s.toCharArray()) {
        map.put(c, map.getOrDefault(c, 0) +1);
    }

    PriorityQueue<Character> heap = new PriorityQueue<>((a, b) -> freq.get(b) - freq.get(a));
    heap.addAll(freq.keySet());

    Queue<Character> cooldown = new LinkedList<>();
    Queue<Integer> cooldownCount = new LinkedList<>();
    StringBuilder result = new StringBuilder();

    while (!heap.isEmpty()) {
        char c = heap.poll();
        result.append(c);
        freq.put(c, freq.get(c) - 1);

        cooldown.offer(c);
        cooldownCount.offer(freq.get(c));

        if (cooldown.size() >= k) {
            char readyChar = cooldown.poll();
            int readyCount = cooldownCount.poll();
            if (readyCount > 0) {
                heap.offer(readyChar);
            }
        }
    }

    return result.length() == s.length() ? result.toString() : "";
}
