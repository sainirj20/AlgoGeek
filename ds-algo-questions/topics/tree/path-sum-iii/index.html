Path Sum III

Problem

Given the root of a binary tree and an integer targetSum, count the number of paths that sum to targetSum. Paths don't need to start at the root or end at a leaf, but must go downward (parent to child).

ExampleInput: root = [10,5,-3,3,2,null,11,3,-2,null,1], targetSum = 8 Output: 3

Approach

This is a downward-path version of Subarray Sum Equals K: track a running prefix sum from the root to the current node in a HashMap of (prefixSum -> count). At each node, the number of valid paths ending here is the count of an earlier prefix sum equal to currentSum - target. Add the current prefix sum to the map before recursing into children, and remove it afterward (backtrack) so it doesn't leak into sibling subtrees.

Time O(n)Space O(n)
Java
public int pathSum(TreeNode root, int targetSum) {
    Map<Long, Integer> prefixCounts = new HashMap<>();
    prefixCounts.put(0L, 1);
    return dfs(root, 0L, targetSum, prefixCounts);
}

private int dfs(TreeNode node, long currentSum, int target, Map<Long, Integer> prefixCounts) {
    if (node == null) {
        return 0;
    }

    currentSum += node.val;
    int count = prefixCounts.getOrDefault(currentSum - target, 0);

    prefixCounts.merge(currentSum, 1, Integer::sum);
    count += dfs(node.left, currentSum, target, prefixCounts);
    count += dfs(node.right, currentSum, target, prefixCounts);
    prefixCounts.merge(currentSum, -1, Integer::sum);

    return count;
}
