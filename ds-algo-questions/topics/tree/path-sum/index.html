4. Tree

Path Sum

Problem

Given the root of a binary tree and an integer targetSum, determine whether the tree has a root-to-leaf path such that the sum of values along the path equals targetSum.

ExampleInput: root = [5,4,8,11,null,13,4,7,2,null,null,null,1], targetSum = 22 Output: true
LeetCode #112

Approach

DFS while subtracting the current node's value from the remaining target. At a leaf, the path is valid if the remaining target has been reduced to exactly 0; otherwise recurse into whichever children exist, looking for any successful path.

Time O(n)Space O(h)
Java
public boolean hasPathSum(TreeNode root, int targetSum) {
    if (root == null) {
        return false;
    }
    if (root.left == null && root.right == null) {
        return root.val == targetSum;
    }

    int remaining = targetSum - root.val;
    return hasPathSum(root.left, remaining) || hasPathSum(root.right, remaining);
}
