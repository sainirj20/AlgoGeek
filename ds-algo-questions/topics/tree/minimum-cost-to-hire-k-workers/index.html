Minimum Cost to Hire K Workers

Problem

Given workers' quality and minimum wage expectation wage arrays, and an integer k, hire exactly k workers so every hired worker is paid proportionally to their quality, at least their minimum wage, minimizing total pay.

ExampleInput: quality = [10,20,5], wage = [70,50,30], k = 2 Output: 30.66667

Approach

Since pay must be proportional to quality, every worker implies a pay 'ratio' (wage[i] / quality[i]); the group's actual ratio must be at least the highest ratio among the hired workers. Sort workers by this ratio ascending, and sweep through, considering each worker in turn as the 'binding' highest-ratio worker: maintain a max-heap of the qualities of the k cheapest (by quality) workers seen so far among those with a ratio no higher than the current one, evicting the highest-quality one whenever the heap exceeds size k. At each step where the heap has exactly k workers, the total cost is ratio * sumOfQualities, a candidate for the answer.

Time O(n log n)Space O(n)
Java
public double mincostToHireWorkers(int[] quality, int[] wage, int k) {
    int n = quality.length;
    double[][] workers = new double[n][2];
    for (int i = 0; i < n; i++) {
        workers[i][0] = (double) wage[i] / quality[i];
        workers[i][1] = quality[i];
    }

    Arrays.sort(workers, (a, b) -> Double.compare(a[0], b[0]));

    PriorityQueue<Double> qualityHeap = new PriorityQueue<>(Collections.reverseOrder());
    double qualitySum = 0;
    double minCost = Double.MAX_VALUE;

    for (double[] worker : workers) {
        qualityHeap.offer(worker[1]);
        qualitySum += worker[1];

        if (qualityHeap.size() > k) {
            qualitySum -= qualityHeap.poll();
        }

        if (qualityHeap.size() == k) {
            minCost = Math.min(minCost, qualitySum * worker[0]);
        }
    }

    return minCost;
}
