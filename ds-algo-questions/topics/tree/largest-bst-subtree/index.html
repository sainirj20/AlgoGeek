🔒Largest BST Subtree

Problem

Given the root of a binary tree, find the size of the largest subtree that is also a valid binary search tree.

ExampleInput: root = [10,5,15,1,8,null,7] Output: 3 (the subtree [5,1,8] with size 3)
📷Diagram placeholder — paste the array traversal image here (save it into this problem's folder and set diagram in solutions.py).
LeetCode #333 (Premium)

Approach

Bottom-up DFS returning, for each subtree, a bundle of info: whether it's a valid BST, its size, and its min/max values. A node forms a valid BST with its children if both children are valid BSTs and the node's value fits strictly between the left subtree's max and the right subtree's min; whenever that holds, track the combined size as a candidate for the largest BST subtree found so far.

Time O(n)Space O(h)
Java
private int largest = 0;

public int largestBSTSubtree(TreeNode root) {
    dfs(root);
    return largest;
}

private int[] dfs(TreeNode node) {
    // returns {isBST (1/0), size, min, max}
    if (node == null) {
        return new int[]{1, 0, Integer.MAX_VALUE, Integer.MIN_VALUE};
    }

    int[] left = dfs(node.left);
    int[] right = dfs(node.right);

    boolean isBST = left[0] == 1 && right[0] == 1
        && node.val > left[3] && node.val < right[2];

    if (isBST) {
        int size = left[1] + right[1] + 1;
        largest = Math.max(largest, size);
        int min = node.left == null ? node.val : left[2];
        int max = node.right == null ? node.val : right[3];
        return new int[]{1, size, min, max};
    }

    return new int[]{0, 0, 0, 0};
}
