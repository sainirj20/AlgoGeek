Path Sum II

Problem

Given the root of a binary tree and an integer targetSum, return all root-to-leaf paths whose values sum to targetSum.

ExampleInput: root = [5,4,8,11,null,13,4,7,2,null,null,5,1], targetSum = 22 Output: [[5,4,11,2],[5,8,4,5]]
LeetCode #113

Approach

Backtracking DFS: maintain a running path list and running sum as recursion goes down. At a leaf whose accumulated sum matches the target, copy the current path into the result. After exploring both children, remove the current node from the path (backtrack) so sibling paths aren't affected.

Time O(n^2) worst case (path copies)Space O(h)
Java
public List<List<Integer>> pathSum(TreeNode root, int targetSum) {
    List<List<Integer>> result = new ArrayList<>();
    dfs(root, targetSum, new ArrayList<>(), result);
    return result;
}

private void dfs(TreeNode node, int remaining, List<Integer> path, List<List<Integer>> result) {
    if (node == null) {
        return;
    }

    path.add(node.val);
    remaining -= node.val;

    if (node.left == null && node.right == null && remaining == 0) {
        result.add(new ArrayList<>(path));
    } else {
        dfs(node.left, remaining, path, result);
        dfs(node.right, remaining, path, result);
    }

    path.remove(path.size() - 1);
}
