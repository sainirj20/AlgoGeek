Delete Nodes And Return Forest

Problem

Given the root of a binary tree and a list of values to delete, delete the nodes with those values, and return the roots of the resulting forest (the remaining trees) in any order.

ExampleInput: root = [1,2,3,4,5,6,7], to_delete = [3,5] Output: [[1,2,null,4],[6],[7]]

Approach

Bottom-up DFS: after recursing into a node's children (so they've already been processed and detached if needed), check whether the current node itself is marked for deletion. If it is, add any of its non-deleted children as new roots of the forest and return null up to the parent (detaching it); if it's the original root and not deleted, add it as a root at the very start.

Time O(n)Space O(n)
Java
public List<TreeNode> delNodes(TreeNode root, int[] to_delete) {
    Set<Integer> deleteSet = new HashSet<>();
    for (int val : to_delete) {
        deleteSet.add(val);
    }

    List<TreeNode> forest = new ArrayList<>();
    if (dfs(root, true, deleteSet, forest) != null) {
        forest.add(root);
    }

    return forest;
}

private TreeNode dfs(TreeNode node, boolean isRoot, Set<Integer> deleteSet, List<TreeNode> forest) {
    if (node == null) {
        return null;
    }

    boolean deleted = deleteSet.contains(node.val);

    if (isRoot && !deleted) {
        forest.add(node);
    }

    node.left = dfs(node.left, deleted, deleteSet, forest);
    node.right = dfs(node.right, deleted, deleteSet, forest);

    return deleted ? null : node;
}
