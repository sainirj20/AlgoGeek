Flatten Binary Tree to Linked List

Problem

Given the root of a binary tree, flatten it into a 'linked list' in place, following preorder traversal order, where each node's right child points to the next node and left is always null.

ExampleInput: root = [1,2,5,3,4,null,6] Output: [1,null,2,null,3,null,4,null,5,null,6]
LeetCode #114

Approach

Process nodes in reverse preorder (right, left, root) using recursion, keeping track of the previously-processed node. At each node, set its right to the previous node, its left to null, then update 'previous' to itself before returning up the call stack -- this builds the flattened list from the tail backward to the head.

Time O(n)Space O(h)
Java
private TreeNode prev = null;

public void flatten(TreeNode root) {
    if (root == null) {
        return;
    }

    flatten(root.right);
    flatten(root.left);

    root.right = prev;
    root.left = null;
    prev = root;
}
