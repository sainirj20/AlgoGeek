Maximum Population Year

Problem

Given people's birth and death years, find the earliest year with the maximum population (a person is counted as alive in every year from birth (inclusive) to death (exclusive)).

ExampleInput: logs = [[1993,1999],[2000,2010]] Output: 1993

LeetCode #2021 Original write-up ↗

Approach

The same delta/prefix-sum trick as Range Addition and Car Pooling: add +1 at each birth year and -1 at each death year in an array indexed by year, then sweep through computing a running population total and tracking the year with the highest total (the earliest one, if ties occur, since the sweep goes in increasing year order).

Time O(n + yearRange)Space O(yearRange)
Java
public int maximumPopulation(int[][] logs) {
    int[] delta = new int[2051];

    for (int[] log : logs) {
        delta[log[0]]++;
        delta[log[1]]--;
    }

    int maxPopulation = 0, bestYear = 1950, running = 0;
    for (int year = 1950; year < 2051; year++) {
        running += delta[year];
        if (running > maxPopulation) {
            maxPopulation = running;
            bestYear = year;
        }
    }

    return bestYear;
}
