The Skyline Problem

Problem

Given a list of buildings as [left, right, height] triples, compute the city's skyline as a list of [x, height] 'key points' where the height changes.

ExampleInput: buildings = [[2,9,10],[3,7,15],[5,12,12],[15,20,10],[19,24,8]] Output: [[2,10],[3,15],[7,12],[12,0],[15,10],[20,8],[24,0]]

Approach

Turn each building into a 'start' event (at its left edge, adding its height) and an 'end' event (at its right edge, removing its height), then sort all events by x-coordinate. Sweep through the events maintaining a max-heap (or TreeMap counting active heights) of currently active building heights; whenever the current maximum active height changes after processing an event, record a new key point at that x-coordinate.

Time O(n log n)Space O(n)
Java
public List<List<Integer>> getSkyline(int[][] buildings) {
    List<int[]> events = new ArrayList<>();
    for (int[] b : buildings) {
        events.add(new int[]{b[0], -b[2]});
        events.add(new int[]{b[1], b[2]});
    }

    events.sort((a, b) -> a[0] != b[0] ? a[0] - b[0] : a[1] - b[1]);

    TreeMap<Integer, Integer> heightCounts = new TreeMap<>(Collections.reverseOrder());
    heightCounts.put(0, 1);
    List<List<Integer>> result = new ArrayList<>();
    int prevMax = 0;

    for (int[] event : events) {
        int x = event[0];
        int h = Math.abs(event[1]);

        if (event[1] < 0) {
            heightCounts.merge(h, 1, Integer::sum);
        } else {
            heightCounts.merge(h, -1, Integer::sum);
            if (heightCounts.get(h) == 0) {
                heightCounts.remove(h);
            }
        }

        int currentMax = heightCounts.firstKey();
        if (currentMax != prevMax) {
            result.add(Arrays.asList(x, currentMax));
            prevMax = currentMax;
        }
    }

    return result;
}
