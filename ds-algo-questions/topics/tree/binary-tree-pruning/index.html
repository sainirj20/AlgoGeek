Binary Tree Pruning

Problem

Given the root of a binary tree where every node's value is 0 or 1, remove every subtree that does not contain a 1.

ExampleInput: root = [1,null,0,0,1] Output: [1,null,0,null,1]

LeetCode #814 Original write-up ↗

Approach

Bottom-up DFS: recursively prune both children first. A node can itself be pruned (replaced with null) exactly when both of its (already-pruned) children are null and its own value is 0.

Time O(n)Space O(h)
Java
public TreeNode pruneTree(TreeNode root) {
    if (root == null) {
        return null;
    }

    root.left = pruneTree(root.left);
    root.right = pruneTree(root.right);

    if (root.left == null && root.right == null && root.val == 0) {
        return null;
    }

    return root;
}
