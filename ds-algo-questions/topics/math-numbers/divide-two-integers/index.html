Divide Two Integers

Problem

Given two integers, divide them without using multiplication, division, or mod operators, returning the truncated quotient (and clamping to 32-bit signed integer range).

ExampleInput: dividend = 10, divisor = 3 Output: 3

LeetCode #29

Approach

Repeated doubling (like long division in binary): for each step, find the largest power-of-two multiple of the divisor that still fits within the remaining dividend (by doubling the divisor and a counter together), subtract that multiple from the dividend, add the counter to the quotient, and repeat until the remaining dividend is smaller than the divisor.

Time O(log^2(dividend))Space O(1)
Java
public int divide(int dividend, int divisor) {
    if (dividend == Integer.MIN_VALUE && divisor == -1) {
        return Integer.MAX_VALUE;
    }

    boolean negative = (dividend < 0) ^ (divisor < 0);
    long absDividend = Math.abs((long) dividend);
    long absDivisor = Math.abs((long) divisor);
    long quotient = 0;

    while (absDividend >= absDivisor) {
        long tempDivisor = absDivisor;
        long multiple = 1;

        while (absDividend >= (tempDivisor << 1)) {
            tempDivisor <<= 1;
            multiple <<= 1;
        }

        absDividend -= tempDivisor;
        quotient += multiple;
    }

    return negative ? (int) -quotient : (int) quotient;
}
