Self Crossing

Problem

Given an array of movement distances where you walk north, then west, then south, then east, repeating in that rotating order, determine whether your path crosses itself.

ExampleInput: distance = [2,1,1,2] Output: true

LeetCode #335 Original write-up ↗

Approach

Rather than simulating full geometry, check three specific crossing patterns at each step i against the 3 (and sometimes 4-5) most recent segment lengths: (1) the current segment crosses the segment from 3 steps ago; (2) the current segment touches the segment from 4 steps ago at a corner; (3) the current segment crosses the segment from 5 steps ago in a spiral. Checking these known geometric cases covers every way the path can self-intersect.

Time O(n)Space O(1)
Java
public boolean isSelfCrossing(int[] distance) {
    int n = distance.length;

    for (int i = 3; i < n; i++) {
        if (distance[i] >= distance[i - 2] && distance[i - 1] <= distance[i - 3]) {
            return true;
        }

        if (i >= 4 && distance[i - 1] == distance[i - 3]
                && distance[i] + distance[i - 4] >= distance[i - 2]) {
            return true;
        }

        if (i >= 5 && distance[i - 2] >= distance[i - 4]
                && distance[i] + distance[i - 4] >= distance[i - 2]
                && distance[i - 1] <= distance[i - 3]
                && distance[i - 1] + distance[i - 5] >= distance[i - 3]) {
            return true;
        }
    }

    return false;
}
