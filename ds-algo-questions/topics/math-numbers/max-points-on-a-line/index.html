Max Points on a Line

Problem

Given an array of points on a 2D plane, find the maximum number of points that lie on the same straight line.

ExampleInput: points = [[1,1],[2,2],[3,3]] Output: 3
📷Diagram placeholder — paste the array traversal image here (save it into this problem's folder and set diagram in solutions.py).
LeetCode #149

Approach

For each point, compute the slope to every other point (represented as a reduced fraction of (dy, dx) using their GCD, to avoid floating-point precision issues), and count how many other points share each slope in a HashMap. The maximum count (plus 1 for the point itself) across all slopes, maximized over every starting point, is the answer.

Time O(n^2)Space O(n)
Java
public int maxPoints(int[][] points) {
    int n = points.length;
    if (n <= 2) {
        return n;
    }

    int maxCount = 1;

    for (int i = 0; i < n; i++) {
        Map<String, Integer> slopeCounts = new HashMap<>();
        int duplicates = 0;
        int best = 0;

        for (int j = i + 1; j < n; j++) {
            int dx = points[j][0] - points[i][0];
            int dy = points[j][1] - points[i][1];

            if (dx == 0 && dy == 0) {
                duplicates++;
                continue;
            }

            int gcd = gcd(dx, dy);
            dx /= gcd;
            dy /= gcd;

            if (dx < 0 || (dx == 0 && dy < 0)) {
                dx = -dx;
                dy = -dy;
            }

            String key = dx + "/" + dy;
            int count = slopeCounts.merge(key, 1, Integer::sum);
            best = Math.max(best, count);
        }

        maxCount = Math.max(maxCount, best + duplicates + 1);
    }

    return maxCount;
}

private int gcd(int a, int b) {
    a = Math.abs(a);
    b = Math.abs(b);
    while (b != 0) {
        int temp = b;
        b = a % b;
        a = temp;
    }
    return a == 0 ? 1 : a;
}
