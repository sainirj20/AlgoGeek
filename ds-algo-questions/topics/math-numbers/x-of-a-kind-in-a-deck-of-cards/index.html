X of a Kind in a Deck of Cards

Problem

Given an array representing a deck of cards where deck[i] is the value written on the ith card, determine whether the deck can be split into groups of exactly x >= 2 cards each, where every group has cards of the same value.

ExampleInput: deck = [1,2,3,4,4,3,2,1] Output: true (groups of x=2: [1,1],[2,2],[3,3],[4,4])

Approach

Count the frequency of each card value, then check whether the GCD of all the frequency counts is at least 2 -- if so, that GCD (or any divisor of it that's >=2) is a valid group size x.

Time O(n)Space O(n)
Java
public boolean hasGroupsSizeX(int[] deck) {
    Map<Integer, Integer> counts = new HashMap<>();
    for (int card : deck) {
        counts.merge(card, 1, Integer::sum);
    }

    int gcdValue = 0;
    for (int count : counts.values()) {
        gcdValue = gcd(gcdValue, count);
    }

    return gcdValue >= 2;
}

private int gcd(int a, int b) {
    return b == 0 ? a : gcd(b, a % b);
}
