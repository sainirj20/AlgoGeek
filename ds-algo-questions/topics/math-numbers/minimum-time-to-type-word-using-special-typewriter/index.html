Minimum Time to Type Word Using Special Typewriter

Problem

There is a special typewriter with a pointer starting at character 'a' on a circular dial of the 26 lowercase letters. Moving the pointer one letter clockwise or counter-clockwise takes 1 second, and typing the character under the pointer takes 1 second. Return the minimum time to type a given word.

ExampleInput: word = "abc" Output: 5

Approach

For each consecutive pair of characters, the pointer can move clockwise or counter-clockwise around the 26-letter circle -- take the shorter of the two directions: min(diff, 26 - diff) where diff is the absolute difference between the two characters' positions. Sum these movement costs plus 1 second per character typed.

Time O(n)Space O(1)
Java
public int minTimeToType(String word) {
    int time = word.length();
    char current = 'a';

    for (char c : word.toCharArray()) {
        int diff = Math.abs(c - current);
        time += Math.min(diff, 26 - diff);
        current = c;
    }

    return time;
}
