Integer to English Words

Problem

Given a non-negative integer, convert it to its English words representation.

ExampleInput: num = 1234567 Output: "One Million Two Hundred Thirty Four Thousand Five Hundred Sixty Seven"

LeetCode #273

Approach

Break the number into groups of three digits (ones, thousands, millions, billions), converting each three-digit group to words using lookup tables for ones/teens/tens, then appending the group's scale word (Thousand, Million, Billion). Process groups from the largest scale down, skipping any all-zero groups.

Time O(1) (bounded digit groups)Space O(1)
Java
private static final String[] BELOW_20 = {
    "", "One", "Two", "Three", "Four", "Five", "Six", "Seven", "Eight", "Nine", "Ten",
    "Eleven", "Twelve", "Thirteen", "Fourteen", "Fifteen", "Sixteen", "Seventeen", "Eighteen", "Nineteen"
};
private static final String[] TENS = {
    "", "", "Twenty", "Thirty", "Forty", "Fifty", "Sixty", "Seventy", "Eighty", "Ninety"
};
private static final String[] THOUSANDS = {"", "Thousand", "Million", "Billion"};

public String numberToWords(int num) {
    if (num == 0) {
        return "Zero";
    }

    StringBuilder result = new StringBuilder();
    int groupIndex = 0;

    while (num > 0) {
        if (num % 1000 != 0) {
            StringBuilder group = new StringBuilder();
            helper(num % 1000, group);
            group.append(THOUSANDS[groupIndex]).append(" ");
            result.insert(0, group);
        }
        num /= 1000;
        groupIndex++;
    }

    return result.toString().trim().replaceAll(" +", " ");
}

private void helper(int num, StringBuilder sb) {
    if (num >= 100) {
        sb.append(BELOW_20[num / 100]).append(" Hundred ");
        num %= 100;
    }
    if (num >= 20) {
        sb.append(TENS[num / 10]).append(" ");
        num %= 10;
    }
    if (num > 0) {
        sb.append(BELOW_20[num]).append(" ");
    }
}
