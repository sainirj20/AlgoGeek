Patching Array

Problem

Given a sorted array of positive integers and a target integer n, return the minimum number of elements to add to the array so that any number in range [1, n] can be formed as a sum of some subset of the array.

ExampleInput: nums = [1,5,10], n = 20 Output: 2

Approach

Maintain reach, the largest value provably formable as [1, reach] so far. Walk through nums in order: if the next number is <= reach + 1, it extends the reachable range without needing a patch; otherwise, patch with the value reach + 1 (the smallest necessary addition), which doubles the reach without consuming an array element. Repeat until reach >= n.

Time O(n + log(target))Space O(1)
Java
public int minPatches(int[] nums, int n) {
    long reach = 0;
    int patches = 0;
    int i = 0;

    while (reach < n) {
        if (i < nums.length && nums[i] <= reach + 1) {
            reach += nums[i];
            i++;
        } else {
            reach += reach + 1;
            patches++;
        }
    }

    return patches;
}
