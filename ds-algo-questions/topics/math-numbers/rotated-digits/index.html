Rotated Digits

Problem

A number is 'good' if, after rotating each digit 180 degrees, it becomes a different valid number (digits 3, 4, 7 make it invalid; 0, 1, 8 stay the same; 2 <-> 5 and 6 <-> 9 change but stay valid). Count how many numbers in [1, n] are good.

ExampleInput: n = 10 Output: 4 (2, 5, 6, 9 are good)

Approach

For each number from 1 to n, check every digit: if any digit is 3, 4, or 7, the number is invalid; otherwise, track whether at least one digit is from {2, 5, 6, 9} (which actually changes upon rotation) -- if so it's 'different' and counts as good.

Time O(n log n)Space O(1)
Java
public int rotatedDigits(int n) {
    int count = 0;

    for (int i = 1; i <= n; i++) {
        if (isGood(i)) {
            count++;
        }
    }

    return count;
}

private boolean isGood(int num) {
    boolean isDifferent = false;

    while (num > 0) {
        int digit = num % 10;
        if (digit == 3 || digit == 4 || digit == 7) {
            return false;
        }
        if (digit == 2 || digit == 5 || digit == 6 || digit == 9) {
            isDifferent = true;
        }
        num /= 10;
    }

    return isDifferent;
}
