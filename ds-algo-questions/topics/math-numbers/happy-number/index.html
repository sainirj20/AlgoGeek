Happy Number

Problem

A happy number eventually reaches 1 when repeatedly replaced by the sum of the squares of its digits; otherwise it loops endlessly in a cycle that doesn't include 1. Determine whether a given number is happy.

ExampleInput: n = 19 Output: true (19 -> 82 -> 68 -> 100 -> 1)

Approach

Use Floyd's cycle detection (fast/slow pointers), applying the digit-square-sum transformation as the 'next' function. If the number is happy, the fast pointer reaches 1; if not, the fast and slow pointers will eventually meet somewhere inside an infinite cycle (that never includes 1).

Time O(log n) per transformation, bounded overallSpace O(1)
Java
public boolean isHappy(int n) {
    int slow = n, fast = n;

    do {
        slow = sumOfSquares(slow);
        fast = sumOfSquares(sumOfSquares(fast));
    } while (slow != fast);

    return slow == 1;
}

private int sumOfSquares(int n) {
    int sum = 0;
    while (n > 0) {
        int digit = n % 10;
        sum += digit * digit;
        n /= 10;
    }
    return sum;
}
