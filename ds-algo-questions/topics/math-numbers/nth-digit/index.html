Nth Digit

Problem

Given an integer n, return the nth digit of the infinite sequence formed by writing every positive integer in order: 123456789101112...

ExampleInput: n = 11 Output: 0 (the sequence is ...9,1,0,... and the 11th digit is 0, from "10")

LeetCode #400

Approach

Numbers with d digits contribute 9 * 10^(d-1) * d digits total to the sequence. Subtract off the digit counts for 1-digit, 2-digit, 3-digit, ... numbers until landing in the correct digit-length group, then compute which specific number and which digit within that number the remaining offset points to.

Time O(log n)Space O(1)
Java
public int findNthDigit(int n) {
    long digitLength = 1;
    long count = 9;
    long start = 1;

    while (n > digitLength * count) {
        n -= (int) (digitLength * count);
        digitLength++;
        count *= 10;
        start *= 10;
    }

    long number = start + (n - 1) / digitLength;
    int digitIndex = (int) ((n - 1) % digitLength);

    return String.valueOf(number).charAt(digitIndex) - '0';
}
