Text Justification

Problem

Given an array of words and a maximum width, format the text into justified lines of exactly that width, distributing extra spaces as evenly as possible (left-justifying the last line).

ExampleInput: words = ["This","is","an","example","of","text","justification."], maxWidth = 16 Output: ["This is an","example of text","justification. "]

Approach

Greedily pack as many words as possible into each line without exceeding maxWidth (accounting for at least one space between words). For a completed non-last line with multiple words, distribute the extra spaces as evenly as possible across the gaps, front-loading any remainder gaps with one extra space each. Single-word lines and the last line are left-justified and padded with trailing spaces.

Time O(total characters)Space O(total characters) for output
Java
public List<String> fullJustify(String[] words, int maxWidth) {
    List<String> result = new ArrayList<>();
    int i = 0;

    while (i < words.length) {
        int j = i;
        int lineLength = 0;

        while (j < words.length && lineLength + words[j].length() + (j - i) <= maxWidth) {
            lineLength += words[j].length();
            j++;
        }

        StringBuilder line = new StringBuilder();
        int wordCount = j - i;
        int totalSpaces = maxWidth - lineLength;

        if (j == words.length || wordCount == 1) {
            for (int k = i; k < j; k++) {
                line.append(words[k]);
                if (k < j - 1) {
                    line.append(" ");
                }
            }
            while (line.length() < maxWidth) {
                line.append(" ");
            }
        } else {
            int gaps = wordCount - 1;
            int spacePerGap = totalSpaces / gaps;
            int extra = totalSpaces % gaps;

            for (int k = i; k < j; k++) {
                line.append(words[k]);
                if (k < j - 1) {
                    int spaces = spacePerGap + (k - i < extra ? 1 : 0);
                    for (int s = 0; s < spaces; s++) {
                        line.append(" ");
                    }
                }
            }
        }

        result.add(line.toString());
        i = j;
    }

    return result;
}
