Integer to Roman

Problem

Given an integer between 1 and 3999, convert it to a Roman numeral.

ExampleInput: num = 1994 Output: "MCMXCIV"
📷Diagram placeholder — paste the array traversal image here (save it into this problem's folder and set diagram in solutions.py).
LeetCode #12 Original write-up ↗

Approach

Use a lookup table of values and symbols ordered from largest to smallest, including the special subtractive combinations (CM, CD, XC, XL, IX, IV). Greedily subtract the largest value that fits from the remaining number, appending its symbol each time, until the number reaches 0.

Time O(1) (bounded by 13 symbol groups)Space O(1)
Java
private static final int[] VALUES = {1000, 900, 500, 400, 100, 90, 50, 40, 10, 9, 5, 4, 1};
private static final String[] SYMBOLS = {"M", "CM", "D", "CD", "C", "XC", "L", "XL", "X", "IX", "V", "IV", "I"};

public String intToRoman(int num) {
    StringBuilder result = new StringBuilder();

    for (int i = 0; i < VALUES.length; i++) {
        while (num >= VALUES[i]) {
            num -= VALUES[i];
            result.append(SYMBOLS[i]);
        }
    }

    return result.toString();
}
