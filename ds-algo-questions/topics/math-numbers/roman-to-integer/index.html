Roman to Integer

Problem

Given a Roman numeral, convert it to an integer.

ExampleInput: s = "MCMXCIV" Output: 1994
📷Diagram placeholder — paste the array traversal image here (save it into this problem's folder and set diagram in solutions.py).
LeetCode #13 Original write-up ↗

Approach

Map each Roman symbol to its value, then scan left to right: if a symbol's value is smaller than the NEXT symbol's value, it's part of a subtractive pair, so subtract it; otherwise add it. This naturally handles cases like IV (4) or IX (9).

Time O(n)Space O(1)
Java
public int romanToInt(String s) {
    Map<Character, Integer> values = Map.of(
        'I', 1, 'V', 5, 'X', 10, 'L', 50, 'C', 100, 'D', 500, 'M', 1000
    );

    int total = 0;
    for (int i = 0; i < s.length(); i++) {
        int value = values.get(s.charAt(i));

        if (i + 1 < s.length() && value < values.get(s.charAt(i + 1))) {
            total -= value;
        } else {
            total += value;
        }
    }

    return total;
}
