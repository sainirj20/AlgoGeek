Find K Pairs with Smallest Sums

Problem

Given two sorted arrays nums1, nums2, and an integer k, find the k pairs (u, v) -- one element from each array -- with the smallest sums.

ExampleInput: nums1 = [1,7,11], nums2 = [2,4,6], k = 3 Output: [[1,2],[1,4],[1,6]]

Approach

Seed a min-heap by pairing each element of nums1 with nums2[0] (its smallest possible partner), tracking each entry's index into nums2. Repeatedly pop the smallest pair into the result, then push that same nums1 element paired with the next nums2 element, until k pairs are collected.

Time O(k log(min(n, k)))Space O(min(n, k))
Java
public List<int[]> kSmallestPairs(int[] nums1, int[] nums2, int k) {
    List<int[]> result = new ArrayList<>();
    if (nums1.length == 0 || nums2.length == 0 || k == 0) {
        return result;
    }

    PriorityQueue<int[]> heap = new PriorityQueue<>(
        (a, b) -> (nums1[a[0]] + nums2[a[1]]) - (nums1[b[0]] + nums2[b[1]])
    );

    for (int i = 0; i < nums1.length && i < k; i++) {
        heap.offer(new int[]{i, 0});
    }

    while (k-- > 0 && !heap.isEmpty()) {
        int[] idx = heap.poll();
        int i = idx[0], j = idx[1];
        result.add(new int[]{nums1[i], nums2[j]});

        if (j + 1 < nums2.length) {
            heap.offer(new int[]{i, j + 1});
        }
    }

    return result;
}
