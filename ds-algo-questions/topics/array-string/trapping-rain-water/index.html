Trapping Rain Water

Problem

Given n non-negative integers representing an elevation map where each bar has width 1, compute how much water it can trap after raining.

Example 1Input: height = [0,1,0,2,1,0,1,3,2,1,2,1] Output: 6
Example 2Input: height = [4,2,0,3,2,5] Output: 9
LeetCode #42

Approach

The water trapped above any bar is bounded by the shorter of the tallest bar to its left and the tallest bar to its right. Rather than precomputing both arrays, two pointers can track leftMax/rightMax while closing in from both ends: whichever side currently has the smaller max is the side whose water level is already fully determined, so that pointer can safely advance and add its contribution.

Time O(n)Space O(1)
Java
public int trap(int[] height) {
    int result = 0;

    if(height==null || height.length<=2)
        return result;

    int left[] = new int[height.length];
    int right[]= new int[height.length];

    //scan from left to right
    int max = height[0];
    left[0] = height[0];
    for(int i=1; i< height.length; i++) {
        max = Math.max(max, height[i]);
        left[i]=max;
    }

    //scan from right to left
    max = height[height.length-1];
    right[height.length-1]=height[height.length-1];
    for(int i=height.length-2; i>=0; i--) {
        max = Math.max(max, height[i]);
        right[i]=max;
    }

    //calculate totoal
    for(int i=0; i< height.length; i++){
        result += Math.min(left[i],right[i]) - height[i];
    }
    return result;
}
