🔒Shortest Word Distance II

Problem

Design a class that's initialized once with a word list, then must answer many 'shortest distance between two words' queries efficiently.

ExampleWordDistance(["practice","makes","perfect","coding","makes"]) shortest("coding", "makes") -> 1

LeetCode #244

Approach

Precompute a map from each word to the sorted list of indices where it occurs. For a query, walk both index lists with two pointers, always advancing whichever one currently points at the smaller index -- this finds the minimum gap between any pair of indices in linear time instead of checking every pair.

Time O(n) build; O(k1 + k2) per querySpace O(n)
Java
class WordDistance {
    private Map<String, List<Integer>> indexMap = new HashMap<>();

    public WordDistance(String[] words) {
        for (int i = 0; i < words.length; i++) {
            indexMap.computeIfAbsent(words[i], k -> new ArrayList<>()).add(i);
        }
    }

    public int shortest(String word1, String word2) {
        List<Integer> l1 = indexMap.get(word1);
        List<Integer> l2 = indexMap.get(word2);
        int i = 0, j = 0;
        int min = Integer.MAX_VALUE;

        while (i < l1.size() && j < l2.size()) {
            min = Math.min(min, Math.abs(l1.get(i) - l2.get(j)));
            if (l1.get(i) < l2.get(j)) {
                i++;
            } else {
                j++;
            }
        }

        return min;
    }
}
