Remove Duplicates from Sorted Array I

Problem

You're given an integer array nums sorted in non-decreasing order. Remove the duplicate values in place so each distinct value appears only once, keeping their original relative order, then return k, the number of distinct values.

It doesn't matter what you leave beyond the first k positions of nums — only the first k elements are checked.

Example 1Input: nums = [1,1,2] Output: k = 2, nums = [1,2,_]
Example 2Input: nums = [0,0,1,1,1,2,2,3,3,4] Output: k = 5, nums = [0,1,2,3,4,_,_,_,_,_]

Approach

Because the array is already sorted, every run of equal values sits next to each other — so a single left-to-right pass is enough to tell whether we've reached a new value.

The solution keeps two pointers. j marks the last index of the duplicate-free section built so far, and i scans ahead through the rest of the array. Whenever nums[i] differs from nums[j], that's a new distinct value: advance j and copy nums[i] into that slot. By the time i reaches the end, j + 1 is exactly the count of distinct values, sitting in order at the front of the array.

Time O(n)Space O(1)
Java
public int removeDuplicates(int[] nums) {
    if (nums == null || nums.length == 0) {
        return 0;
    }

    int j = 0;
    for (int i = 1; i < nums.length; i++) {
        if (nums[i] != nums[j]) {
            j++;
            nums[j] = nums[i];
        }
    }

    return j + 1;
}
