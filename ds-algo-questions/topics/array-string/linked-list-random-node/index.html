Linked List Random Node

Problem

Given a singly linked list of unknown length, design a class that returns a uniformly random node's value, without using extra space proportional to the list's length.

Examplelist = 1 -> 2 -> 3 getRandom() returns 1, 2, or 3, each with probability 1/3
📷Diagram placeholder — paste the array traversal image here (save it into this problem's folder and set diagram in solutions.py).
LeetCode #382

Approach

Reservoir sampling with a single pass. Walk the list keeping a running count of nodes seen; for the i-th node visited (1-indexed), replace the currently held result with that node's value with probability 1/i. This guarantees every node ends up chosen with equal probability 1/n, without knowing n in advance.

Time O(n) per callSpace O(1)
Java
// Assumes LeetCode's standard singly-linked-list definition (ListNode).

class Solution {
    private ListNode head;
    private Random random = new Random();

    public Solution(ListNode head) {
        this.head = head;
    }

    public int getRandom() {
        int result = head.val;
        ListNode node = head.next;
        int count = 2;

        while (node != null) {
            if (random.nextInt(count) == 0) {
                result = node.val;
            }
            node = node.next;
            count++;
        }

        return result;
    }
}
