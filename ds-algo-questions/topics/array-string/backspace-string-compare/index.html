Backspace String Compare

Problem

Given strings s and t made of lowercase letters and # (a backspace), return whether the two strings are equal once every backspace has been applied.

Example 1Input: s = "ab#c", t = "ad#c" Output: true (both become "ac")
Example 2Input: s = "ab##", t = "c#d#" Output: true (both become "")

Approach

Process each string from its right end with a 'skip' counter: seeing # increments the count (the next real character encountered should be dropped), and a positive count consumes one character without keeping it. Walking both strings backward this way, skip over backspaced characters and compare the next surviving character from each side -- no extra string needs to be built.

Time O(m + n)Space O(1)
Java
public boolean backspaceCompare(String s, String t) {
    int i = s.length() - 1;
    int j = t.length() - 1;

    while (i >= 0 || j >= 0) {
        i = nextValidIndex(s, i);
        j = nextValidIndex(t, j);

        if (i >= 0 && j >= 0) {
            if (s.charAt(i) != t.charAt(j)) {
                return false;
            }
        } else if (i >= 0 || j >= 0) {
            return false;
        }
        i--;
        j--;
    }

    return true;
}

private int nextValidIndex(String str, int index) {
    int skip = 0;
    while (index >= 0) {
        if (str.charAt(index) == '#') {
            skip++;
            index--;
        } else if (skip > 0) {
            skip--;
            index--;
        } else {
            break;
        }
    }
    return index;
}
