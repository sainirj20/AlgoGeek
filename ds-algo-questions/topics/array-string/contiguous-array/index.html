Contiguous Array

Problem

Given a binary array nums, find the maximum length of a contiguous subarray with an equal number of 0s and 1s.

ExampleInput: nums = [0,1,0] Output: 2

LeetCode #525 Original write-up ↗

Approach

Treat every 0 as -1 and every 1 as +1; the problem becomes finding the longest subarray that sums to zero. Track a running sum and the first index where each running-sum value was seen -- whenever the same running sum reoccurs, the subarray between those two points has an equal count of 0s and 1s.

Time O(n)Space O(n)
Java
public int findMaxLength(int[] nums) {
    Map<Integer, Integer> firstIndexOfSum = new HashMap<>();
    firstIndexOfSum.put(0, -1);

    int sum = 0, max = 0;
    for (int i = 0; i < nums.length; i++) {
        sum += (nums[i] == 1) ? 1 : -1;
        if (firstIndexOfSum.containsKey(sum)) {
            max = Math.max(max, i - firstIndexOfSum.get(sum));
        } else {
            firstIndexOfSum.put(sum, i);
        }
    }

    return max;
}
