Container With Most Water

Problem

Given n non-negative integers where each represents a vertical line at that index, find two lines that, together with the x-axis, form a container holding the most water.

ExampleInput: height = [1,8,6,2,5,4,8,3,7] Output: 49

LeetCode #11

Approach

Start with the widest possible container -- both end pointers -- and move inward. The water held is capped by the shorter of the two lines, so moving the taller pointer inward can only shrink the width without raising the cap; only moving the shorter pointer has any chance of finding a taller line and increasing the area.

Time O(n)Space O(1)
Java
public int maxArea(int[] height) {
    int left = 0, right = height.length - 1;
    int max = 0;

    while (left < right) {
        int area = (right - left) * Math.min(height[left], height[right]);
        max = Math.max(max, area);

        if (height[left] < height[right]) {
            left++;
        } else {
            right--;
        }
    }

    return max;
}
