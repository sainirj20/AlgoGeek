Search Insert Position

Problem

Given a sorted array of distinct integers and a target, return the index if the target is found, or the index where it would be inserted to keep the array sorted.

Example[1,3,5,6], target = 5 -> 2 [1,3,5,6], target = 2 -> 1 [1,3,5,6], target = 7 -> 4

Approach

Standard binary search. When the loop ends without an exact match, the low pointer has naturally converged on exactly the correct insertion index.

Time O(log n)Space O(1)
Java
public int searchInsert(int[] nums, int target) {
    int lo = 0, hi = nums.length - 1;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;
        if (nums[mid] == target) {
            return mid;
        } else if (nums[mid] < target) {
            lo = mid + 1;
        } else {
            hi = mid - 1;
        }
    }
    return lo;
}
