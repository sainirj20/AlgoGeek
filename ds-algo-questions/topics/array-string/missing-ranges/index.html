🔒Missing Ranges

Problem

Given a sorted integer array nums and a bound [lower, upper], return the ranges that are missing from nums within that bound, in the same "a->b" / "a" format used by Summary Ranges.

Example 1Input: nums = [0,1,3,50,75], lower = 0, upper = 99 Output: ["2","4->49","51->74","76->99"]

Approach

Track an expected value starting at lower. Walk through nums (plus one extra virtual step for upper + 1, to flush any trailing gap): whenever the current number is greater than expected, there's a gap from expected to current - 1 — record it — then move expected to just past the current number.

Time O(n)Space O(1) extra (excluding output)
Java
public List<String> findMissingRanges(int[] nums, int lower, int upper) {
    List<String> result = new ArrayList<>();
    long expected = lower;

    for (int i = 0; i <= nums.length; i++) {
        long current = (i == nums.length) ? (long) upper + 1 : nums[i];
        if (current > expected) {
            result.add(formatRange(expected, current - 1));
        }
        expected = current + 1;
    }

    return result;
}

private String formatRange(long start, long end) {
    return start == end ? String.valueOf(start) : start + "->" + end;
}
