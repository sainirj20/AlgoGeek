🔒Two Sum III - Data Structure Design

Problem

Design a class supporting add(number) to add a number to an internal store, and find(value) to check whether any two numbers currently stored add up to value.

Exampleadd(1); add(3); add(5); find(4) -> true find(7) -> false

Approach

Keep a HashMap from each number to its occurrence count. For find, check every distinct stored key k: does value - k also exist? If a number is its own complement, it needs to have been added at least twice to pair with itself.

Time O(1) add, O(n) findSpace O(n)
Java
class TwoSum {
    private Map<Integer, Integer> counts = new HashMap<>();

    public void add(int number) {
        counts.merge(number, 1, Integer::sum);
    }

    public boolean find(int value) {
        for (int num : counts.keySet()) {
            int complement = value - num;
            if (complement == num) {
                if (counts.get(num) > 1) {
                    return true;
                }
            } else if (counts.containsKey(complement)) {
                return true;
            }
        }
        return false;
    }
}
