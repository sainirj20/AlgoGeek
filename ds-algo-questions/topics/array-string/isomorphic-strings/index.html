Isomorphic Strings

Problem

Given strings s and t, determine if they are isomorphic -- the characters in s can be consistently, one-to-one replaced to get t.

Example 1Input: s = "egg", t = "add" Output: true
Example 2Input: s = "foo", t = "bar" Output: false

LeetCode #205

Approach

Keep two maps: one for the s -> t character mapping and one for t -> s. Checking consistency in both directions at once is what guarantees a true one-to-one mapping -- it prevents two different characters in s from being mapped to the same character in t.

Time O(n)Space O(n)
Java
public boolean isIsomorphic(String s, String t) {
    if (s.length() != t.length()) {
        return false;
    }

    Map<Character, Character> mapST = new HashMap<>();
    Map<Character, Character> mapTS = new HashMap<>();

    for (int i = 0; i < s.length(); i++) {
        char c1 = s.charAt(i);
        char c2 = t.charAt(i);

        if (mapST.containsKey(c1) && mapST.get(c1) != c2) {
            return false;
        }
        if (mapTS.containsKey(c2) && mapTS.get(c2) != c1) {
            return false;
        }

        mapST.put(c1, c2);
        mapTS.put(c2, c1);
    }

    return true;
}
