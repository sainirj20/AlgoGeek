🔒Wiggle Sort

Problem

Given an unsorted array nums, reorder it in place so that nums[0] <= nums[1] >= nums[2] <= nums[3]....

ExampleInput: nums = [3,5,2,1,6,4] Output: one valid answer: [3,5,1,6,2,4]

Approach

A single greedy pass suffices. At each boundary between position i-1 and i, check whether the expected inequality (based on whether i is odd or even) already holds; if it doesn't, swap the two elements. This local fix-up is enough to make the whole array satisfy the wiggle pattern.

Time O(n)Space O(1)
Java
public void wiggleSort(int[] nums) {
    for (int i = 1; i < nums.length; i++) {
        boolean shouldBeGreater = (i % 2 == 1);
        if (shouldBeGreater && nums[i] < nums[i - 1]) {
            swap(nums, i, i - 1);
        } else if (!shouldBeGreater && nums[i] > nums[i - 1]) {
            swap(nums, i, i - 1);
        }
    }
}

private void swap(int[] nums, int i, int j) {
    int tmp = nums[i];
    nums[i] = nums[j];
    nums[j] = tmp;
}
