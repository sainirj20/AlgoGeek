Maximum Height by Stacking Cuboids

Problem

Given cuboids as [width, length, height] triples that can each be freely reoriented, one cuboid can be stacked on another only if every one of its dimensions is <= the one below it. Return the maximum total height achievable by stacking any subset.

ExampleInput: cuboids = [[50,45,20],[95,37,53],[45,23,12]] Output: 190

Approach

First normalize every cuboid by sorting its own three dimensions ascending -- this guarantees that if one cuboid can contain another in some orientation, its sorted dimensions dominate the other's, component-wise. Sort all cuboids by their normalized dimensions, then run a Longest-Increasing-Subsequence-style DP where dp[i] is the max stack height ending with cuboid i, built from any earlier cuboid that fits entirely underneath it in all three dimensions.

Time O(n²)Space O(n)
Java
public int maxHeight(int[][] cuboids) {
    for (int[] c : cuboids) {
        Arrays.sort(c);
    }
    Arrays.sort(cuboids, (a, b) ->
        a[0] != b[0] ? a[0] - b[0] : (a[1] != b[1] ? a[1] - b[1] : a[2] - b[2]));

    int n = cuboids.length;
    int[] dp = new int[n];
    int best = 0;

    for (int i = 0; i < n; i++) {
        dp[i] = cuboids[i][2];
        for (int j = 0; j < i; j++) {
            if (cuboids[j][0] <= cuboids[i][0]
                    && cuboids[j][1] <= cuboids[i][1]
                    && cuboids[j][2] <= cuboids[i][2]) {
                dp[i] = Math.max(dp[i], dp[j] + cuboids[i][2]);
            }
        }
        best = Math.max(best, dp[i]);
    }

    return best;
}
