Two Furthest Houses With Different Colors

Problem

Given an array colors representing house colors along a street, find the maximum distance between two houses whose colors differ.

Example 1Input: colors = [1,1,1,6,1,1,1] Output: 3
Example 2Input: colors = [1,8,3,8,3] Output: 4

Approach

The optimal pair always involves one of the two array endpoints, so it's enough to check, for each house, its distance from whichever endpoint has a different color than it -- no need to compare every pair of houses.

Time O(n)Space O(1)
Java
public int maxDistance(int[] colors) {
    int n = colors.length;
    int best = 0;

    for (int i = 0; i < n; i++) {
        if (colors[i] != colors[0]) {
            best = Math.max(best, i);
        }
        if (colors[i] != colors[n - 1]) {
            best = Math.max(best, n - 1 - i);
        }
    }

    return best;
}
