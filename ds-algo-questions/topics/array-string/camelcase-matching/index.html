Camelcase Matching

Problem

Given an array of query strings and a pattern, a query matches the pattern if every uppercase letter in pattern appears in the query, in order, and lowercase letters may be inserted anywhere else. Return a boolean for each query.

ExampleInput: queries = ["FooBar","FooBarTest","FootBall","FrameBuffer","ForceFeedBack"], pattern = "FB" Output: [true,false,true,true,false]

Approach

Walk each query with a pointer into the pattern: whenever the query's character matches the current pattern character, advance the pattern pointer. An uppercase letter in the query that doesn't match fails the query immediately -- uppercase letters must align exactly with the pattern, in order. Lowercase letters that don't match are simply skipped. A query passes only if the pattern pointer reaches the end.

Time O(n × k)Space O(1) extra
Java
public List<Boolean> camelMatch(String[] queries, String pattern) {
    List<Boolean> result = new ArrayList<>();
    for (String query : queries) {
        result.add(matches(query, pattern));
    }
    return result;
}

private boolean matches(String query, String pattern) {
    int j = 0;
    for (int i = 0; i < query.length(); i++) {
        char c = query.charAt(i);
        if (j < pattern.length() && pattern.charAt(j) == c) {
            j++;
        } else if (Character.isUpperCase(c)) {
            return false;
        }
    }
    return j == pattern.length();
}
