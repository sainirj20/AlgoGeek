Max Sum of Rectangle No Larger Than K

Problem

Given an m x n matrix and an integer k, find the maximum sum of a rectangle in the matrix such that its sum is no larger than k.

ExampleInput: matrix = [[1,0,1],[0,-2,3]], k = 2 Output: 2

Approach

Fix a pair of left/right column boundaries and compress every row between them into a single running row-sum array, reducing to a 1D problem. For each prefix sum of that compressed array, use a TreeSet of previously-seen prefix sums to find, via ceiling(), the smallest earlier prefix sum that's >= currentSum - k -- giving the best subarray sum not exceeding k for this column range. Repeating over every column-boundary pair covers all possible rectangles.

Time O(cols² × rows × log rows)Space O(rows)
Java
public int maxSumSubmatrix(int[][] matrix, int k) {
    int rows = matrix.length, cols = matrix[0].length;
    int result = Integer.MIN_VALUE;

    for (int left = 0; left < cols; left++) {
        int[] rowSums = new int[rows];

        for (int right = left; right < cols; right++) {
            for (int r = 0; r < rows; r++) {
                rowSums[r] += matrix[r][right];
            }

            TreeSet<Integer> prefixSums = new TreeSet<>();
            prefixSums.add(0);
            int sum = 0;

            for (int rowSum : rowSums) {
                sum += rowSum;
                Integer ceiling = prefixSums.ceiling(sum - k);
                if (ceiling != null) {
                    result = Math.max(result, sum - ceiling);
                }
                prefixSums.add(sum);
            }
        }
    }

    return result;
}
