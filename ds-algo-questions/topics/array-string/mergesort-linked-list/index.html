Merge Sort (Linked List)

Problem

Sort a linked list in ascending order using merge sort. This is the standard approach for LeetCode's 'Sort List' problem, and achieves O(n log n) time with O(log n) space (recursion stack only) -- unlike an array, a linked list can be split and merged without needing extra O(n) storage for the merge step.

ExampleInput: head = [4,2,1,3] Output: [1,2,3,4]

Approach

Find the middle of the list using the slow/fast pointer technique (fast moves two nodes for every one node slow moves), then split the list into two halves at that midpoint. Recursively sort each half, then merge the two now-sorted halves together node by node, always attaching the smaller of the two current heads. The base case is a list of length 0 or 1, which is trivially sorted.

Time O(n log n)Space O(log n) recursion stack
Java
public ListNode sortList(ListNode head) {
    if (head == null || head.next == null) {
        return head;
    }

    ListNode slow = head, fast = head.next;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }

    ListNode secondHalf = slow.next;
    slow.next = null;

    ListNode left = sortList(head);
    ListNode right = sortList(secondHalf);

    return merge(left, right);
}

private ListNode merge(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(0);
    ListNode tail = dummy;

    while (l1 != null && l2 != null) {
        if (l1.val <= l2.val) {
            tail.next = l1;
            l1 = l1.next;
        } else {
            tail.next = l2;
            l2 = l2.next;
        }
        tail = tail.next;
    }

    tail.next = (l1 != null) ? l1 : l2;
    return dummy.next;
}
