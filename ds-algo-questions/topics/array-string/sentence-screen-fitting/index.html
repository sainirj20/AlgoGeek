🔒Sentence Screen Fitting

Problem

Given a rows × cols screen and a sentence (an array of words), find how many times the sentence can be fitted onto the screen. A word cannot be split across lines, and consecutive words on a line need exactly one separating space.

ExampleInput: sentence = ["hello","world"], rows = 2, cols = 8 Output: 1

Approach

Join the whole sentence into one string separated by spaces, with one trailing space, and imagine it repeating forever. For each row, jump a running position ahead by cols characters in this imaginary infinite string, then back up if that landed mid-word (checked by whether the following character is a space) until reaching a space boundary. Dividing the total characters consumed by the joined sentence's length gives the number of complete sentences fitted.

Time O(rows × cols / len)Space O(n) for the joined string
Java
public int wordsTyping(String[] sentence, int rows, int cols) {
    String joined = String.join(" ", sentence) + " ";
    int length = joined.length();
    int start = 0;

    for (int i = 0; i < rows; i++) {
        start += cols;
        if (joined.charAt(start % length) == ' ') {
            start++;
        } else {
            while (start > 0 && joined.charAt((start - 1) % length) != ' ') {
                start--;
            }
        }
    }

    return start / length;
}
