Candy

Problem

There are n children standing in a line, each assigned a rating. Every child must receive at least one candy, and any child with a higher rating than an immediate neighbor must receive more candies than that neighbor. Find the minimum number of candies needed.

Example 1Input: ratings = [1,0,2] Output: 5 (candies = [2,1,2])
Example 2Input: ratings = [1,2,2] Output: 4 (candies = [1,2,1])

Approach

This is solved with two greedy passes instead of trying to satisfy both neighbors at once. A left-to-right pass gives every child one more candy than their left neighbor whenever their rating is higher, satisfying the "left" constraint. A right-to-left pass does the same for the "right" constraint. Since each child's final candy count must satisfy both constraints simultaneously, take the max of what each pass produced for that position.

Time O(n)Space O(n)
Java
public int candy(int[] ratings) {
    int n = ratings.length;
    int[] candies = new int[n];
    for (int i = 0; i < n; i++) {
        candies[i] = 1;
    }

    // left-to-right pass: satisfy the "higher than left neighbor" rule
    for (int i = 1; i < n; i++) {
        if (ratings[i] > ratings[i - 1]) {
            candies[i] = candies[i - 1] + 1;
        }
    }

    // right-to-left pass: satisfy the "higher than right neighbor" rule
    int total = candies[n - 1];
    for (int i = n - 2; i >= 0; i--) {
        if (ratings[i] > ratings[i + 1]) {
            candies[i] = Math.max(candies[i], candies[i + 1] + 1);
        }
        total += candies[i];
    }

    return total;
}
