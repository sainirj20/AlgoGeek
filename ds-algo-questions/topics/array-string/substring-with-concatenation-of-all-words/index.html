Substring with Concatenation of All Words

Problem

Given a string s and an array words of same-length words, find every starting index where a substring of s is exactly a concatenation of every word in words, each used once, in any order.

ExampleInput: s = "barfoothefoobarman", words = ["foo","bar"] Output: [0,9]

Approach

Since every word has the same length, each word-sized chunk of s can be treated as a single unit. For every possible starting offset within one word's length, slide a window forward one word at a time while tracking a running frequency count of words seen inside it: an unrecognized chunk resets the window past it, a word count exceeding what's needed shrinks the window from the left until valid again, and reaching the full word count records a match.

Time O(n × wordLen)Space O(words.length × wordLen)
Java
public List<Integer> findSubstring(String s, String[] words) {
    List<Integer> result = new ArrayList<>();
    if (words.length == 0) {
        return result;
    }

    int wordLen = words[0].length();
    int totalWords = words.length;

    Map<String, Integer> wordCount = new HashMap<>();
    for (String w : words) {
        wordCount.merge(w, 1, Integer::sum);
    }

    for (int offset = 0; offset < wordLen; offset++) {
        int left = offset;
        int count = 0;
        Map<String, Integer> windowCount = new HashMap<>();

        for (int i = offset; i + wordLen <= s.length(); i += wordLen) {
            String chunk = s.substring(i, i + wordLen);

            if (!wordCount.containsKey(chunk)) {
                windowCount.clear();
                count = 0;
                left = i + wordLen;
                continue;
            }

            windowCount.merge(chunk, 1, Integer::sum);
            count++;

            while (windowCount.get(chunk) > wordCount.get(chunk)) {
                String leftChunk = s.substring(left, left + wordLen);
                windowCount.put(leftChunk, windowCount.get(leftChunk) - 1);
                count--;
                left += wordLen;
            }

            if (count == totalWords) {
                result.add(left);
                String leftChunk = s.substring(left, left + wordLen);
                windowCount.put(leftChunk, windowCount.get(leftChunk) - 1);
                count--;
                left += wordLen;
            }
        }
    }

    return result;
}
