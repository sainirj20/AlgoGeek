Minimum Window Substring

Problem

Given strings s and t, find the minimum window in s that contains every character of t (with at least the same multiplicity).

ExampleInput: s = "ADOBECODEBANC", t = "ABC" Output: "BANC"
LeetCode #76

Approach

A sliding window with a target frequency map for t and a running window frequency map. Expand the right edge; once the window fully satisfies t's requirement (tracked with a counter of distinct characters currently matched), try shrinking from the left as far as possible while it stays valid, recording the shortest window seen along the way.

Time O(n)Space O(k) (k = distinct chars in t)
Java
public String minWindow(String s, String t) {
        if (t.length() > s.length()) return "";

        Map < Character, Integer> freqMap = new HashMap< > ();
        for (int i=0; i< t.length(); i++) {
            char ch = t.charAt(i);
            freqMap.put(ch, freqMap.getOrDefault(ch, 0) + 1);
        }

        int []result = new int[] {-1, -1};
        int min = Integer.MAX_VALUE;
        int count = freqMap.size();
        int left = 0, right = 0;
        while (right < s.length()) {
            char ch = s.charAt(right);
            if (freqMap.containsKey(ch)) {
                int freq = freqMap.get(ch) - 1;
                freqMap.put(ch, freq);
                if (freq == 0) count--;
            }
            right ++;
            while (count == 0) {
                if (min > right - left) {
                    min = right - left;
                    result[0] = left;
                    result[1] = right;
                }

                char tail = s.charAt(left);
                if (freqMap.containsKey(tail)) {
                    int freq = freqMap.get(tail) + 1;
                    freqMap.put(tail, freq);
                    if (freq > 0) count++;
                }
                left++;
            }
        }

        return (result[0] == -1) ? "" : s.substring(result[0], result[1]);
}
