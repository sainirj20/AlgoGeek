Remove Zero Sum Consecutive Nodes from Linked List

Problem

Given the head of a linked list, repeatedly remove consecutive sequences of nodes whose values sum to 0 until none remain, then return the resulting list.

ExampleInput: head = [1,2,-3,3,1] Output: [3,1] (or [1,2,1] -- multiple valid answers exist)

Approach

Using a dummy head, compute a running prefix sum while walking the list once, recording the node reached at each prefix-sum value in a HashMap (later nodes overwrite earlier ones for the same sum). Walking the list a second time, whenever the current prefix sum has been seen before, everything between the earlier node with that same sum and the current node summed to zero -- so unlinking that whole stretch is as simple as pointing the earlier node directly to the current node's next.

Time O(n)Space O(n)
Java
// Assumes LeetCode's standard singly-linked-list definition:
// public class ListNode {
//     int val;
//     ListNode next;
//     ListNode(int val) { this.val = val; }
// }

public ListNode removeZeroSumSublists(ListNode head) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    Map<Integer, ListNode> lastNodeAtSum = new HashMap<>();
    int sum = 0;
    for (ListNode node = dummy; node != null; node = node.next) {
        sum += node.val;
        lastNodeAtSum.put(sum, node);
    }

    sum = 0;
    for (ListNode node = dummy; node != null; node = node.next) {
        sum += node.val;
        node.next = lastNodeAtSum.get(sum).next;
    }

    return dummy.next;
}
