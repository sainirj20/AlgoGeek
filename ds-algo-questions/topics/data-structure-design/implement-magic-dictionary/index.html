Implement Magic Dictionary

Problem

Design a dictionary supporting buildDict(words) and search(searchWord), where search returns true if changing exactly one letter of searchWord can produce a word in the dictionary.

ExamplebuildDict(["hello","leetcode"]); search("hello") -> false; search("hhllo") -> true

LeetCode #676 Original write-up ↗

Approach

Store all dictionary words in a HashSet for O(1) exact lookups. For a search word, try every position, substituting each of the 25 other letters at that position, and check whether the resulting word (which must differ from the original in that one letter) is in the set -- succeeding on the first match found.

Time O(L * 26) per search (L = word length)Space O(total letters)
Java
class MagicDictionary {
    private Set<String> words = new HashSet<>();

    public void buildDict(String[] dictionary) {
        words.addAll(Arrays.asList(dictionary));
    }

    public boolean search(String searchWord) {
        char[] chars = searchWord.toCharArray();

        for (int i = 0; i < chars.length; i++) {
            char original = chars[i];
            for (char c = 'a'; c <= 'z'; c++) {
                if (c == original) {
                    continue;
                }
                chars[i] = c;
                if (words.contains(new String(chars))) {
                    chars[i] = original;
                    return true;
                }
            }
            chars[i] = original;
        }

        return false;
    }
}
