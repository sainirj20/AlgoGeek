Snapshot Array

Problem

Design an array-like structure supporting set(index, val), snap() (takes a snapshot, returns its id), and get(index, snapId) (returns the value of an index at the time of a given snapshot).

ExampleSnapshotArray(3); set(0,5); snap() -> 0; set(0,6); get(0,0) -> 5

Approach

Instead of copying the whole array on every snapshot (expensive), store each index's history as a list of (snapId, value) pairs, only appending a new entry when set actually changes that index after a new snapshot has been taken. get binary searches that index's history for the latest entry with snapId <= the requested one.

Time O(1) set/snap, O(log n) getSpace O(total sets)
Java
class SnapshotArray {
    private List<List<int[]>> history;
    private int snapId = 0;

    public SnapshotArray(int length) {
        history = new ArrayList<>();
        for (int i = 0; i < length; i++) {
            List<int[]> entry = new ArrayList<>();
            entry.add(new int[]{0, 0});
            history.add(entry);
        }
    }

    public void set(int index, int val) {
        List<int[]> entries = history.get(index);
        int[] last = entries.get(entries.size() - 1);

        if (last[0] == snapId) {
            last[1] = val;
        } else {
            entries.add(new int[]{snapId, val});
        }
    }

    public int snap() {
        return snapId++;
    }

    public int get(int index, int snap_id) {
        List<int[]> entries = history.get(index);
        int lo = 0, hi = entries.size() - 1, resultIndex = 0;

        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            if (entries.get(mid)[0] <= snap_id) {
                resultIndex = mid;
                lo = mid + 1;
            } else {
                hi = mid - 1;
            }
        }

        return entries.get(resultIndex)[1];
    }
}
