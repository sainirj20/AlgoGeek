Peeking Iterator

Problem

Given an existing Iterator interface, design an iterator that additionally supports peek() -- returning the next element without advancing.

ExamplePeekingIterator([1,2,3]); peek() -> 1; next() -> 1; next() -> 2; hasNext() -> true

Approach

Cache one element ahead: eagerly pull the next element from the underlying iterator and store it. peek() simply returns the cached value; next() returns the cached value and refills the cache by pulling another element (if available); hasNext() checks whether a cached value exists.

Time O(1) per operationSpace O(1)
Java
class PeekingIterator implements Iterator<Integer> {
    private Iterator<Integer> iterator;
    private Integer cached;

    public PeekingIterator(Iterator<Integer> iterator) {
        this.iterator = iterator;
        if (iterator.hasNext()) {
            cached = iterator.next();
        }
    }

    public Integer peek() {
        return cached;
    }

    @Override
    public Integer next() {
        Integer result = cached;
        cached = iterator.hasNext() ? iterator.next() : null;
        return result;
    }

    @Override
    public boolean hasNext() {
        return cached != null;
    }
}
