Insert Delete GetMostFrequent O(1)

Problem

Design a data structure supporting insert(val), delete(val), and getMostFrequent() (returns any element with the highest current frequency), all in O(1).

Exampleinsert(1); insert(1); insert(2); getMostFrequent() -> 1
📷Diagram placeholder — paste the array traversal image here (save it into this problem's folder and set diagram in solutions.py).
Classic interview question

Approach

This mirrors the frequency-bucket structure from LFU Cache: a value -> frequency map, and a frequency -> set of values map, plus a running maximum frequency. Insert/delete update a value's frequency and move it between buckets, adjusting the running maximum as buckets empty out or grow; getMostFrequent just reads any element from the bucket at the maximum frequency.

Time O(1) per operationSpace O(n)
Java
class FrequencyTracker {
    private Map<Integer, Integer> valueToFreq = new HashMap<>();
    private Map<Integer, LinkedHashSet<Integer>> freqToValues = new HashMap<>();
    private int maxFreq = 0;

    public void insert(int val) {
        int freq = valueToFreq.getOrDefault(val, 0);
        if (freq > 0) {
            freqToValues.get(freq).remove(val);
        }

        int newFreq = freq + 1;
        valueToFreq.put(val, newFreq);
        freqToValues.computeIfAbsent(newFreq, k -> new LinkedHashSet<>()).add(val);
        maxFreq = Math.max(maxFreq, newFreq);
    }

    public void delete(int val) {
        if (!valueToFreq.containsKey(val)) {
            return;
        }

        int freq = valueToFreq.get(val);
        freqToValues.get(freq).remove(val);

        if (freq == 1) {
            valueToFreq.remove(val);
        } else {
            valueToFreq.put(val, freq - 1);
            freqToValues.computeIfAbsent(freq - 1, k -> new LinkedHashSet<>()).add(val);
        }

        if (freqToValues.get(freq).isEmpty() && freq == maxFreq) {
            maxFreq--;
        }
    }

    public int getMostFrequent() {
        return freqToValues.get(maxFreq).iterator().next();
    }
}
