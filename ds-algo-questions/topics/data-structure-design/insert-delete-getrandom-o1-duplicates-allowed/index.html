Insert Delete GetRandom O(1) - Duplicates allowed

Problem

Same as Insert Delete GetRandom O(1), but the collection may contain duplicate values.

Exampleinsert(1); insert(1); insert(2); getRandom() -> 1 with probability 2/3, 2 with probability 1/3

LeetCode #381

Approach

Use the same array-plus-index-map idea, but map each value to a SET of indices (since it can appear multiple times). Removal picks any one of the value's stored indices, swaps that position with the last array element (updating the swapped element's index set), and removes the last element, exactly as before.

Time O(1) per operationSpace O(n)
Java
class RandomizedCollection {
    private List<Integer> values = new ArrayList<>();
    private Map<Integer, Set<Integer>> indices = new HashMap<>();
    private Random random = new Random();

    public boolean insert(int val) {
        boolean isNew = !indices.containsKey(val) || indices.get(val).isEmpty();
        indices.computeIfAbsent(val, k -> new LinkedHashSet<>()).add(values.size());
        values.add(val);
        return isNew;
    }

    public boolean remove(int val) {
        if (!indices.containsKey(val) || indices.get(val).isEmpty()) {
            return false;
        }

        int index = indices.get(val).iterator().next();
        indices.get(val).remove(index);

        int lastIndex = values.size() - 1;
        int lastVal = values.get(lastIndex);

        values.set(index, lastVal);
        if (index != lastIndex) {
            indices.get(lastVal).remove(lastIndex);
            indices.get(lastVal).add(index);
        }

        values.remove(lastIndex);
        return true;
    }

    public int getRandom() {
        return values.get(random.nextInt(values.size()));
    }
}
