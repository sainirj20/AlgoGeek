Product of the Last K Numbers

Problem

Design a class supporting add(num) (append a new number to a stream) and getProduct(k) (returns the product of the last k numbers added).

Exampleadd(3); add(0); add(2); add(5); add(4); getProduct(2) -> 20; getProduct(3) -> 40

LeetCode #1352 Original write-up ↗

Approach

Maintain a running prefix-product array, but reset it (clearing back to just [1]) whenever a 0 is added, since a 0 makes every product spanning past it equal to 0. Then getProduct(k) is answered via division of prefix products (prefix[n] / prefix[n-k]), returning 0 directly if k exceeds how many numbers have been added since the last reset.

Time O(1) per operation (amortized)Space O(n)
Java
class ProductOfNumbers {
    private List<Integer> prefixProducts = new ArrayList<>();

    public ProductOfNumbers() {
        prefixProducts.add(1);
    }

    public void add(int num) {
        if (num == 0) {
            prefixProducts.clear();
            prefixProducts.add(1);
        } else {
            int last = prefixProducts.get(prefixProducts.size() - 1);
            prefixProducts.add(last * num);
        }
    }

    public int getProduct(int k) {
        int n = prefixProducts.size() - 1;
        if (k > n) {
            return 0;
        }
        return prefixProducts.get(n) / prefixProducts.get(n - k);
    }
}
