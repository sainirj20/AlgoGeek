Data Stream as Disjoint Intervals

Problem

Design a class that receives integers from a data stream one at a time via addNum(value) and can return the disjoint intervals currently covering all numbers seen so far via getIntervals().

ExampleaddNum(1); getIntervals() -> [[1,1]] addNum(3); getIntervals() -> [[1,1],[3,3]] addNum(2); getIntervals() -> [[1,3]]

Approach

Maintain intervals in a TreeMap keyed by each interval's start value. When a new number arrives, use floorKey/ceilingKey to find neighboring intervals that the new number touches or falls between; merge with the interval before if it extends its end by exactly 1, merge with the interval after if it extends its start by exactly 1 (possibly merging both into one), or insert a brand new single-number interval otherwise.

Time O(log n) per addNumSpace O(n)
Java
class SummaryRanges {
    private TreeMap<Integer, Integer> intervals = new TreeMap<>();

    public void addNum(int value) {
        if (intervals.containsKey(value)) {
            return;
        }

        Integer lowerKey = intervals.lowerKey(value);
        Integer higherKey = intervals.higherKey(value);

        boolean mergeLower = lowerKey != null && intervals.get(lowerKey) + 1 == value;
        boolean mergeHigher = higherKey != null && higherKey - 1 == value;

        if (mergeLower && mergeHigher) {
            intervals.put(lowerKey, intervals.get(higherKey));
            intervals.remove(higherKey);
        } else if (mergeLower) {
            intervals.put(lowerKey, value);
        } else if (mergeHigher) {
            int end = intervals.get(higherKey);
            intervals.remove(higherKey);
            intervals.put(value, end);
        } else {
            intervals.put(value, value);
        }
    }

    public int[][] getIntervals() {
        int[][] result = new int[intervals.size()][2];
        int i = 0;
        for (Map.Entry<Integer, Integer> entry : intervals.entrySet()) {
            result[i][0] = entry.getKey();
            result[i][1] = entry.getValue();
            i++;
        }
        return result;
    }
}
