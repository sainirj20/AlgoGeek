LFU Cache

Problem

Design a Least Frequently Used (LFU) cache with a fixed capacity, supporting get and put in O(1), evicting the least frequently used entry (breaking ties by least recently used) when full.

ExampleLFUCache(2); put(1,1); put(2,2); get(1) -> 1; put(3,3) (evicts 2, since 1 was used more)

Approach

Maintain a key -> (value, frequency) map, a frequency -> ordered set/list of keys map (each bucket ordered by recency, e.g. via a LinkedHashSet), and the current minimum frequency present in the cache. Every access bumps a key's frequency (moving it to the next bucket); eviction removes the least-recently-used key from the minimum-frequency bucket, and the minimum frequency pointer is updated whenever a new key is inserted (frequency 1) or a bucket becomes empty.

Time O(1) per operationSpace O(capacity)
Java
class LFUCache {
    private int capacity;
    private int minFreq;
    private Map<Integer, Integer> values = new HashMap<>();
    private Map<Integer, Integer> freqs = new HashMap<>();
    private Map<Integer, LinkedHashSet<Integer>> freqBuckets = new HashMap<>();

    public LFUCache(int capacity) {
        this.capacity = capacity;
    }

    public int get(int key) {
        if (!values.containsKey(key)) {
            return -1;
        }
        bumpFrequency(key);
        return values.get(key);
    }

    public void put(int key, int value) {
        if (capacity == 0) {
            return;
        }

        if (values.containsKey(key)) {
            values.put(key, value);
            bumpFrequency(key);
            return;
        }

        if (values.size() >= capacity) {
            int evictKey = freqBuckets.get(minFreq).iterator().next();
            freqBuckets.get(minFreq).remove(evictKey);
            values.remove(evictKey);
            freqs.remove(evictKey);
        }

        values.put(key, value);
        freqs.put(key, 1);
        freqBuckets.computeIfAbsent(1, k -> new LinkedHashSet<>()).add(key);
        minFreq = 1;
    }

    private void bumpFrequency(int key) {
        int freq = freqs.get(key);
        freqBuckets.get(freq).remove(key);

        if (freqBuckets.get(freq).isEmpty() && freq == minFreq) {
            minFreq++;
        }

        freqs.put(key, freq + 1);
        freqBuckets.computeIfAbsent(freq + 1, k -> new LinkedHashSet<>()).add(key);
    }
}
