Insert Delete GetRandom O(1)

Problem

Design a data structure supporting insert(val), remove(val), and getRandom() (returns a uniformly random element), all in average O(1) time.

Exampleinsert(1); remove(2) -> false; insert(2); getRandom() -> 1 or 2; remove(1) -> true

LeetCode #380

Approach

Combine an ArrayList (for O(1) random access, needed by getRandom) with a HashMap from value to its index in the list. To remove a value in O(1) without leaving a gap, swap it with the LAST element of the list first (updating the swapped element's index in the map), then remove the last element directly.

Time O(1) per operationSpace O(n)
Java
class RandomizedSet {
    private List<Integer> values = new ArrayList<>();
    private Map<Integer, Integer> indexOf = new HashMap<>();
    private Random random = new Random();

    public boolean insert(int val) {
        if (indexOf.containsKey(val)) {
            return false;
        }
        indexOf.put(val, values.size());
        values.add(val);
        return true;
    }

    public boolean remove(int val) {
        if (!indexOf.containsKey(val)) {
            return false;
        }

        int index = indexOf.get(val);
        int lastVal = values.get(values.size() - 1);

        values.set(index, lastVal);
        indexOf.put(lastVal, index);

        values.remove(values.size() - 1);
        indexOf.remove(val);

        return true;
    }

    public int getRandom() {
        return values.get(random.nextInt(values.size()));
    }
}
