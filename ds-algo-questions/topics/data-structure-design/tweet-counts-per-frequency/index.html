Tweet Counts Per Frequency

Problem

Design a class recording tweets with recordTweet(tweetName, time) and returning tweet counts bucketed by minute/hour/day via getTweetCountsPerFrequency(freq, tweetName, startTime, endTime).

ExamplerecordTweet("tweet",0); recordTweet("tweet",60); getTweetCountsPerFrequency("minute","tweet",0,59) -> [1]

LeetCode #1348 Original write-up ↗

Approach

Store each tweet name's recorded times in a list. For a query, compute the bucket size (60 for minute, 3600 for hour, 86400 for day), determine the number of buckets spanning [startTime, endTime], and for every recorded time in range, increment the count of the bucket it falls into (computed via (time - startTime) / bucketSize).

Time O(recorded tweets) per querySpace O(recorded tweets)
Java
class TweetCounts {
    private Map<String, List<Integer>> tweetTimes = new HashMap<>();

    public void recordTweet(String tweetName, int time) {
        tweetTimes.computeIfAbsent(tweetName, k -> new ArrayList<>()).add(time);
    }

    public List<Integer> getTweetCountsPerFrequency(String freq, String tweetName, int startTime, int endTime) {
        int bucketSize = freq.equals("minute") ? 60 : freq.equals("hour") ? 3600 : 86400;
        int buckets = (endTime - startTime) / bucketSize + 1;
        int[] counts = new int[buckets];

        for (int time : tweetTimes.getOrDefault(tweetName, new ArrayList<>())) {
            if (time >= startTime && time <= endTime) {
                counts[(time - startTime) / bucketSize]++;
            }
        }

        List<Integer> result = new ArrayList<>();
        for (int count : counts) {
            result.add(count);
        }
        return result;
    }
}
