Number of Recent Calls

Problem

Design a class that counts recent requests: ping(t) adds a new request at time t and returns the number of requests that occurred in the last 3000 time units (inclusive), given requests always arrive in increasing order of t.

Exampleping(1) -> 1; ping(100) -> 2; ping(3001) -> 3; ping(3002) -> 3

Approach

Use a queue to hold request timestamps in order. On each ping, add the new timestamp, then repeatedly remove timestamps from the front that fall outside the [t - 3000, t] window; the queue's remaining size is the answer.

Time O(1) amortized per callSpace O(3000)
Java
class RecentCounter {
    private Queue<Integer> requests = new LinkedList<>();

    public int ping(int t) {
        requests.offer(t);
        while (requests.peek() < t - 3000) {
            requests.poll();
        }
        return requests.size();
    }
}
