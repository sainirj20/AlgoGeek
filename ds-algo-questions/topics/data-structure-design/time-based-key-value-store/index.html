Time Based Key-Value Store

Problem

Design a time-based key-value store supporting set(key, value, timestamp) and get(key, timestamp), where get returns the value set at the largest timestamp <= the given timestamp.

Exampleset("foo","bar",1); get("foo",1) -> "bar"; get("foo",3) -> "bar"; set("foo","bar2",4); get("foo",4) -> "bar2"

Approach

Store each key's values as a list of (timestamp, value) pairs in insertion order (which is naturally sorted by timestamp, since sets are assumed non-decreasing in time). get binary searches this list for the largest timestamp not exceeding the query timestamp.

Time O(1) set, O(log n) getSpace O(n)
Java
class TimeMap {
    private Map<String, List<int[]>> store = new HashMap<>();
    private Map<String, List<String>> values = new HashMap<>();

    public void set(String key, String value, int timestamp) {
        store.computeIfAbsent(key, k -> new ArrayList<>()).add(new int[]{timestamp});
        values.computeIfAbsent(key, k -> new ArrayList<>()).add(value);
    }

    public String get(String key, int timestamp) {
        if (!store.containsKey(key)) {
            return "";
        }

        List<int[]> timestamps = store.get(key);
        List<String> vals = values.get(key);

        int lo = 0, hi = timestamps.size() - 1, resultIndex = -1;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            if (timestamps.get(mid)[0] <= timestamp) {
                resultIndex = mid;
                lo = mid + 1;
            } else {
                hi = mid - 1;
            }
        }

        return resultIndex == -1 ? "" : vals.get(resultIndex);
    }
}
