Mini Parser

Problem

Given a string representing a nested list of integers (e.g. "[123,[456,[789]]]"), parse it into a NestedInteger structure.

ExampleInput: s = "[123,[456,[789]]]" Output: a NestedInteger representing that nested structure

LeetCode #385 (Premium)

Approach

If the string doesn't start with '[', it's just a single integer. Otherwise, use a stack of NestedInteger lists: on '[', push a new empty list; on a digit run, parse the number and add it to the current top list; on ',', just continue; on ']', pop the completed list and add it as an element of whatever list is now on top (or return it directly if the stack becomes empty).

Time O(n)Space O(n)
Java
public NestedInteger deserialize(String s) {
    if (s.charAt(0) != '[') {
        return new NestedInteger(Integer.parseInt(s));
    }

    Deque<NestedInteger> stack = new ArrayDeque<>();
    NestedInteger current = null;
    int start = 0;

    for (int i = 0; i < s.length(); i++) {
        char c = s.charAt(i);

        if (c == '[') {
            NestedInteger newList = new NestedInteger();
            if (current != null) {
                stack.push(current);
            }
            current = newList;
            start = i + 1;
        } else if (c == ',' || c == ']') {
            if (i > start) {
                current.add(new NestedInteger(Integer.parseInt(s.substring(start, i))));
            }
            start = i + 1;

            if (c == ']' && !stack.isEmpty()) {
                NestedInteger parent = stack.pop();
                parent.add(current);
                current = parent;
            }
        }
    }

    return current;
}
