Largest Rectangle in Histogram

Problem

Given an array of bar heights forming a histogram, find the area of the largest rectangle that can be formed within the histogram.

ExampleInput: heights = [2,1,5,6,2,3] Output: 10
📷Diagram placeholder — paste the array traversal image here (save it into this problem's folder and set diagram in solutions.py).
LeetCode #84

Approach

Use a monotonically increasing stack of bar indices. When a bar shorter than the stack's top is encountered, pop the top and compute the rectangle formed with that popped bar as the height -- its width spans from the (new) stack top's index (exclusive) to the current index (exclusive). Push a sentinel height of 0 at the end to flush out any remaining bars in the stack.

Time O(n)Space O(n)
Java
public int largestRectangleArea(int[] heights) {
    Deque<Integer> stack = new ArrayDeque<>();
    int maxArea = 0;
    int n = heights.length;

    for (int i = 0; i <= n; i++) {
        int currentHeight = (i == n) ? 0 : heights[i];

        while (!stack.isEmpty() && heights[stack.peek()] >= currentHeight) {
            int height = heights[stack.pop()];
            int width = stack.isEmpty() ? i : i - stack.peek() - 1;
            maxArea = Math.max(maxArea, height * width);
        }

        stack.push(i);
    }

    return maxArea;
}
