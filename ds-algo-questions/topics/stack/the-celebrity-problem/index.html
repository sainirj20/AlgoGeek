🔒The Celebrity Problem

Problem

A celebrity is someone everyone else knows, but who knows no one else. Given an n x n matrix knows where knows[i][j] == 1 means person i knows person j, find the celebrity's index, or -1 if none exists.

ExampleInput: n = 3, knows = [[0,1,0],[0,0,0],[0,1,0]] Output: 1

Approach

Use a stack to eliminate non-celebrity candidates in pairs: push everyone onto the stack, then repeatedly pop two people a and b -- if a knows b, a cannot be the celebrity (a celebrity knows no one), so push b back as the surviving candidate; otherwise push a back (since a celebrity is known by everyone, if a doesn't know b, b is disqualified). The single remaining candidate is then verified with one more pass: check that everyone else knows them and that they know no one else.

Time O(n)Space O(n)
Java
public int findCelebrity(int n, int[][] knows) {
    Deque<Integer> stack = new ArrayDeque<>();
    for (int i = 0; i < n; i++) {
        stack.push(i);
    }

    while (stack.size() > 1) {
        int a = stack.pop();
        int b = stack.pop();

        if (knows[a][b] == 1) {
            stack.push(b);
        } else {
            stack.push(a);
        }
    }

    int candidate = stack.pop();
    for (int i = 0; i < n; i++) {
        if (i == candidate) {
            continue;
        }
        if (knows[candidate][i] == 1 || knows[i][candidate] == 0) {
            return -1;
        }
    }

    return candidate;
}
