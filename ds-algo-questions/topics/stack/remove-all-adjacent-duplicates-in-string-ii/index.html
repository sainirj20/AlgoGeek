Remove All Adjacent Duplicates in String II

Problem

Given a string and an integer k, repeatedly remove k adjacent duplicate characters until no such removal is possible, and return the final string.

ExampleInput: s = "deeedbbcccbdaa", k = 3 Output: "aa"

Approach

Use a stack of (character, count) pairs. For each new character, if it matches the top of the stack, increment its count; otherwise push a new pair with count 1. Whenever a count reaches k, pop that pair entirely (those characters cancel out). Reconstruct the final string from what remains on the stack.

Time O(n)Space O(n)
Java
public String removeDuplicates(String s, int k) {
    Deque<int[]> stack = new ArrayDeque<>();

    for (char c : s.toCharArray()) {
        if (!stack.isEmpty() && stack.peek()[0] == c) {
            stack.peek()[1]++;
            if (stack.peek()[1] == k) {
                stack.pop();
            }
        } else {
            stack.push(new int[]{c, 1});
        }
    }

    StringBuilder result = new StringBuilder();
    for (int[] pair : stack) {
        for (int i = 0; i < pair[1]; i++) {
            result.append((char) pair[0]);
        }
    }

    return result.reverse().toString();
}
