Implement a Stack Using an Array

Problem

Implement a stack (push, pop, peek, isEmpty) backed by a plain resizable array, without using any built-in stack or deque class.

Examplepush(1); push(2); peek() -> 2; pop() -> 2; isEmpty() -> false
📷Diagram placeholder — paste the array traversal image here (save it into this problem's folder and set diagram in solutions.py).
Classic interview question

Approach

Keep an array and a size counter marking the top of the stack. push writes to array[size++], doubling the array's capacity first if it's full; pop/peek read/remove from array[size - 1].

Time O(1) amortized per operationSpace O(n)
Java
class ArrayStack {
    private int[] data;
    private int size = 0;

    public ArrayStack(int capacity) {
        data = new int[capacity];
    }

    public void push(int value) {
        if (size == data.length) {
            data = Arrays.copyOf(data, data.length * 2);
        }
        data[size++] = value;
    }

    public int pop() {
        if (isEmpty()) {
            throw new NoSuchElementException("Stack is empty");
        }
        return data[--size];
    }

    public int peek() {
        if (isEmpty()) {
            throw new NoSuchElementException("Stack is empty");
        }
        return data[size - 1];
    }

    public boolean isEmpty() {
        return size == 0;
    }
}
