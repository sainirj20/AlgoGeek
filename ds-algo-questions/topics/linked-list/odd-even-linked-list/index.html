Odd Even Linked List

Problem

Given a singly linked list, group all nodes at odd indices together followed by all nodes at even indices (1-indexed), preserving each group's relative order.

ExampleInput: 1 -> 2 -> 3 -> 4 -> 5 Output: 1 -> 3 -> 5 -> 2 -> 4

LeetCode #328

Approach

Maintain two separate chains (odd and even) built by walking the original list once, alternately attaching nodes to whichever chain they belong to. Finally, splice the even chain's head onto the tail of the odd chain.

Time O(n)Space O(1)
Java
public ListNode oddEvenList(ListNode head) {
    if (head == null || head.next == null) {
        return head;
    }

    ListNode odd = head;
    ListNode even = head.next;
    ListNode evenHead = even;

    while (even != null && even.next != null) {
        odd.next = even.next;
        odd = odd.next;
        even.next = odd.next;
        even = even.next;
    }

    odd.next = evenHead;
    return head;
}
