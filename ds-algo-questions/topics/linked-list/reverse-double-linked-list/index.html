Reverse Double Linked List

Problem

Given the head of a doubly linked list (each node has both next and prev pointers), reverse it in place and return the new head.

ExampleInput: 1 <-> 2 <-> 3 <-> 4 Output: 4 <-> 3 <-> 2 <-> 1
📷Diagram placeholder — paste the array traversal image here (save it into this problem's folder and set diagram in solutions.py).
Classic interview question

Approach

Walk through the list once, and at each node simply swap its next and prev pointers. After swapping every node, what used to be the tail (found by following the swapped pointers to the end) becomes the new head.

Time O(n)Space O(1)
Java
class DoublyListNode {
    int val;
    DoublyListNode next, prev;
    DoublyListNode(int val) { this.val = val; }
}

public DoublyListNode reverse(DoublyListNode head) {
    DoublyListNode current = head;
    DoublyListNode newHead = head;

    while (current != null) {
        DoublyListNode temp = current.next;
        current.next = current.prev;
        current.prev = temp;

        newHead = current;
        current = temp;
    }

    return newHead;
}
