K-th Symbol in Grammar

Problem

Row 1 is "0". Each subsequent row is formed by replacing every 0 in the previous row with "01" and every 1 with "10". Given n and k, find the kth symbol (1-indexed) in row n.

ExampleInput: n = 2, k = 2 Output: 1

Approach

Rather than building the exponentially-growing row, work backward: a symbol at position k in row n is derived from position (k+1)/2 in row n-1, and it equals its parent's value if k is odd (the parent's first expansion character), or the flipped value if k is even (the parent's second expansion character). Recurse up to row 1 (always 0), counting the number of flips along the way -- an even number of flips means the value matches the base case, an odd number means it's flipped.

Time O(n)Space O(n) recursion (or O(1) iteratively)
Java
public int kthGrammar(int n, int k) {
    if (n == 1) {
        return 0;
    }

    int parent = kthGrammar(n - 1, (k + 1) / 2);

    if (k % 2 == 1) {
        return parent;
    } else {
        return parent == 0 ? 1 : 0;
    }
}
