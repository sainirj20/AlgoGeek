Neural Networks & Deep Learning

Overview

Neural networks are function approximators built from layers of simple units. Interviewers use this topic to test whether you understand what's actually happening inside the "black box" — how a signal flows forward, how error flows backward, why certain architectures suit certain data, and the practical failure modes you'll hit when training deep networks.

Perceptron to Multi-Layer Perceptron (MLP)

A single perceptron computes a weighted sum of inputs plus a bias, then applies an activation function: a linear decision boundary. It can only separate linearly separable data (famously, it cannot learn XOR). Stacking perceptrons into an MLP — an input layer, one or more hidden layers, and an output layer, each fully connected to the next — lets the network compose non-linear transformations and approximate arbitrarily complex functions (the universal approximation theorem), provided the hidden layers use non-linear activations.

Non-linear activations are what give a network its expressive power — without them, stacking any number of linear layers collapses mathematically into a single linear layer. ReLU is the default choice for hidden layers because it's cheap to compute and doesn't saturate for positive inputs, though variants like Leaky ReLU and GELU address the "dying neuron" problem where a unit gets stuck outputting zero.

Backpropagation & Gradient Descent

Training a network means finding weights that minimize a loss function. Forward pass: input flows through the layers to produce a prediction, which is compared to the true label via the loss function. Backward pass (backpropagation): using the chain rule, the gradient of the loss with respect to every weight in the network is computed layer by layer, from the output back to the input. Gradient descent then nudges every weight a small step in the direction that reduces the loss.

Gradient descent update rule θ = θ - η ∇θL(θ)
where θ are the model parameters, η is the learning rate, and ∇θL(θ) is the gradient of the loss w.r.t. θ.

In practice, gradients are computed on mini-batches rather than the full dataset (mini-batch SGD), and adaptive optimizers like Adam maintain per-parameter learning rates using running estimates of the gradient's first and second moments, converging faster and more reliably than plain SGD on most deep learning problems.

Vanishing & Exploding Gradients

Because backpropagation multiplies gradients across many layers via the chain rule, repeated multiplication by values less than 1 (common with sigmoid/tanh derivatives) shrinks the gradient exponentially as it reaches earlier layers — the vanishing gradient problem, which stalls learning in deep networks. The opposite, exploding gradients, happens when repeated multiplication by values greater than 1 blows up the gradient, causing unstable, diverging updates.

  • Mitigations for vanishing gradients — ReLU-family activations, residual/skip connections (ResNets), careful weight initialization (Xavier/He), batch normalization, LSTM/GRU gating for recurrent nets.
  • Mitigations for exploding gradients — gradient clipping (cap the norm of the gradient before the update), smaller learning rates, careful initialization.

CNNs vs. RNNs vs. Transformers

ArchitectureCore mechanismStrengthTypical domain
CNNConvolutional filters sharing weights across spatial locationsCaptures local, translation-invariant patternsImages, spatial/grid data
RNN / LSTM / GRURecurrent hidden state updated one step at a timeNaturally models sequence orderTime series, older NLP
TransformerSelf-attention over the whole sequence in parallelLong-range dependencies, fully parallelizable trainingNLP, vision (ViT), most modern foundation models

RNNs process tokens sequentially, which makes long-range dependencies hard to learn (gradients vanish across many time steps) and prevents parallelizing across the sequence during training. Transformers replaced RNNs in most NLP workloads because self-attention lets every position attend directly to every other position in a single layer, and the lack of sequential dependency makes training highly parallelizable on GPUs/TPUs.

Batch Normalization & Dropout

Batch normalization normalizes each layer's activations (per mini-batch) to zero mean and unit variance, then applies a learned scale and shift. This stabilizes and speeds up training by reducing internal covariate shift and allows higher learning rates. Dropout randomly zeroes out a fraction of neurons during each training step, forcing the network to not rely on any single neuron and acting as a strong, cheap regularizer against overfitting; it's turned off at inference time (with activations scaled to compensate).

Interview tip
When asked "why is my deep network not training," walk through the checklist in order: learning rate too high/low, poor weight initialization, missing normalization, vanishing/exploding gradients, and only then consider more exotic causes. Most "my network doesn't learn" bugs are one of these.

Common Interview Questions

Why can't a neural network with only linear activations learn non-linear functions, no matter how many layers it has?
Composing linear functions produces another linear function — stacking layers without non-linear activations is mathematically equivalent to a single linear layer. Non-linear activations (ReLU, sigmoid, tanh) are what allow depth to add real expressive power.
What causes vanishing gradients and how do residual connections help?
Vanishing gradients arise from repeated multiplication of small derivatives (e.g. from sigmoid/tanh) across many layers during backpropagation, shrinking the gradient toward zero for early layers. Residual (skip) connections add the input of a block directly to its output, giving the gradient a shortcut path that bypasses the multiplicative chain, which is a major reason very deep ResNets can train successfully.
Why do Transformers train faster than RNNs on the same hardware, given similar parameter counts?
RNNs process tokens sequentially — each step depends on the previous hidden state — so computation can't be parallelized across the sequence dimension. Transformers compute self-attention over all tokens simultaneously via matrix multiplications, which parallelizes efficiently on GPUs/TPUs.
What's the difference between batch normalization and dropout, and can you use both?
Batch norm normalizes activations to stabilize and accelerate training; dropout randomly disables neurons to reduce overfitting. They address different problems and are often used together, though care is needed (e.g. dropout placement relative to batch norm) since their interaction can sometimes hurt performance if not tuned properly.
When would you choose a CNN over a Transformer for an image task?
CNNs have a strong inductive bias for images — local connectivity and weight sharing — so they train well with less data and less compute. Vision Transformers (ViT) often need larger datasets or pretraining to match or exceed CNN performance because they lack that built-in spatial prior, learning it from data instead.

Key Takeaways

Remember
Non-linear activations give depth its power; backpropagation is just the chain rule applied layer by layer; vanishing/exploding gradients are managed with better activations, initialization, normalization, and skip connections; and the right architecture (CNN, RNN, or Transformer) follows from the structure of your data — spatial, sequential, or long-range/parallel.
